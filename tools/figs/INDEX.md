# 配图索引（:::fig 引用的 id）

由 `python tools/mkfig.py --list` 生成。用法：在课程 md 里写一行

```
:::fig <id> | 图注（会显示在图片下方）
```

| id | 尺寸 | 内容 |
|---|---|---|
| `flow-overview` | 1120x470 | 全流程图。左边灰色虚线框是前端（别人做完交给你的东西），右边蓝色框是后端 8 个阶段。这张图建议先记住三步分组：骨架（① ② ③）、填肉（④ ⑤ ⑥）、体检修补（⑦ ⑧）。 |
| `timing-path` | 1120x400 | 一条时序路径的解剖图。Tcq 是触发器内部的输出延迟，Tlogic 是中间组合逻辑的总延迟，Tsetup 是终点触发器要求数据提前稳定多久。下面两个公式是所有时序分析的基础，务必背下来。 |
| `chip-stack` | 1120x420 | 金属层剖面图。这张图解释了一件让初学者困惑的事：为什么布线工具会抱怨「层不够用」，以及为什么电源要从最上面两层厚金属往下打 via 送到每个单元。 |
