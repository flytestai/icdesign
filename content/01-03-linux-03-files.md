## 1. 查看目录：ls {#ls}

:::goal ls 全部常用选项信手拈来；看懂 ll 的 12 列输出；会建/删目录和文件；通配符用熟。
:::

**ls**（list）：

- 用法 1：`ls` 展示**当前所在目录**的内容；
- 用法 2：`ls 路径` 展示**指定路径**下的内容。

:::fig linux-12 | ls / 与 ls /home 实际效果
:::

### 2）常用 option

| 选项 | 作用 |
|---|---|
| `ls -l` | 展示目录下的**详细信息**（简写 `ll`） |
| `-a` | 展示所有的内容，**包含隐藏文件** |
| `-h` | 人类可读大小，字节换算成 K/M/G |
| `-t` | 按**修改时间**排序，新文件放前面 |
| `-r` | 反转排序（从小到大 / 旧到新） |
| `-S` | 按**文件大小**排序，大的在前 |
| `-R` | 递归列出目录下所有子目录内容 |

**tree 目录**：查看目录层级。

### 组合用法

- 根据时间排序：`ls -lt`；
- 根据时间、文件大小排序：`ls -lrth`（最常用），或 `ll -rth`。

:::tip 工作里最常用的组合
`ll -rth`：按时间从旧到新排列，最新的文件永远在最底下——查 log、找最新 run 必备。
:::

### 3）解析 ll 查看详细内容

以 `lrwxrwxrwx. 1 root root 7 Dec 18 2018` 为例：

- **第一列：内容的类型**
  - `-` 普通的文本文件、log 文件、脚本文件、包
  - `d` 目录
  - `l` 链接 Link
- **第二列到第十列：权限**（下一节细讲，先记住结构）
  - `r` read　`w` write　`x` excute　`-` 无权限
  - `rw-` 所属用户权限；`r--` 所属组的权限；`r--` 其他人的权限
- **第 11 列**：所属用户的用户名
- **第 12 列**：所属组的组名

## 2. 切换目录：cd {#cd}

| 写法 | 作用 |
|---|---|
| `cd 路径` | 进入指定目录 |
| `cd` 或 `cd ~` | 回到当前用户的**家目录** |
| `cd ..` | 切换到**上一级**目录 |
| `cd .` | 当前位置（原地不动） |
| `cd -` | 回到**上一次**打开的目录 |

**相对路径 vs 绝对路径**：

- 相对路径：不以 `/` 开头的路径（从当前位置出发）；
- 绝对路径：以 `/` 开头就是绝对路径（从根出发）。

## 3. 三个查位置的命令 {#locate}

**realpath**：获取某个文件的绝对路径。

```
realpath 文件名
/root/A1/A4/abc
```

**pwd**：显示当前目录的绝对路径。

:::fig linux-13 | pwd 与 realpath 实际效果
:::

**history**：查看命令的历史记录。

## 4. 目录管理 {#mkdir}

**mkdir 创建目录**，语法：

```
mkdir  目录名字
mkdir  目录1  目录2       # 创建多个目录
mkdir  A1/{a,b}          # 同时在 A1 目录下创建 a 和 b 目录
mkdir  -p  a/b/c/d/e     # -p 按照层级创建目录
```

**rmdir 删除空目录**：

```
rmdir  目录名
rmdir  目录1  目录2      # 删除多个空目录
```

**rm -rf 删除非空目录 / 强制删除 / 删除文件**：

```
rm  -rf  目录名
```

:::pitfall rm -rf 是不可逆操作
删错目录没有回收站可找。敲 rm -rf 之前先停一秒确认路径，尤其是带通配符的时候。
:::

## 5. 文件管理 {#touch}

```
touch  文件名            # 创建文件
touch  文件1  文件2  文件3   # 创建多个文件
rm    文件名             # 删除文件
rm  -rf  文件名          # 强制删除
```

### 通配符

`*` 表示 **0 个或任意多个字符**：

| 通配符 | 匹配 |
|---|---|
| `a1*` | 以 a1 开头的文件或目录 |
| `*b` | 以 b 结尾的文件或目录 |
| `*a*` | 包含 a 的文件或目录 |
| `a*b` | 以 a 开头 b 结尾的文件或目录 |
| `a*y*b` | a 开头、中间有 y、b 结尾 |

比如目录里有 `a12nn3b`、`b123kkb`、`a234yyb`：`a*y*b` 只匹配 `a234yyb`。
