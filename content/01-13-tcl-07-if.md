## if-elseif-else 语法 {#if}

:::goal 会写 if/elseif/else 并背下四大铁律；会用 gets stdin 读输入；会用 rand() 造随机数；能做出成绩等级判断和猜数字游戏。
:::

根据条件执行不同代码块，条件表达式需用 `{}` 包裹，支持比较运算符（`==` 等于、`!=` 不等于、`>` 大于、`<` 小于、`<=` 小于等于、`>=` 大于等于）；逻辑运算：与 `&&`、或 `||`。

**语法骨架**：

```tcl
if {条件1} {代码块1} elseif {条件2} {代码块2} else {代码块3}
```

**完整示例**：

:::tclrun
set score 85
if {$score >= 90} {
    puts "成绩等级：A（优秀）"
} elseif {$score >= 80} {
    puts "成绩等级：B（良好）"
} elseif {$score >= 60} {
    puts "成绩等级：C（及格）"
} else {
    puts "成绩等级：D（不及格）"
}
;# 输出：成绩等级：B（良好）
:::

## 四大语法铁律（文档强调，初学者最常踩坑） {#rules}

1. **铁律 1**：`}` 和 `elseif` / `else` 必须**同一行**，中间必须**有空格**。
2. **铁律 2**：`if` 后面的条件必须包在 `{}` 里，而且 `{` 必须跟在条件后面，**不能换行**。
3. **铁律 3**：所有大括号、运算符，必须是**英文半角符号**，禁止中文括号 / 空格。
4. **铁律 4**：TCL 是严格一行一条命令：`if` 是单条完整命令，不能用换行把 `}` 和 `elseif` 切开。

:::note 为什么有这些规定？
因为 `{...}` 是"分组"——`}` 换行会让 TCL 以为命令提前结束了。（第 2 讲的分组原理在这里兑现。）
:::

## 输入（gets stdin） {#gets}

`gets stdin 变量` 相当于 Python 的 `input()`——从标准输入读一行存进变量：

:::tclrun
puts "Please enter the score："
gets stdin score

if {$score >= 90} {
    puts "youxiu"
} elseif {$score >= 80} {
    puts "lianghao"
} else {
    puts "jiayou"
}
:::

练习台里的玩法：直接在下面输入行敲 `gets stdin score` 回车，再敲 `85` 回车，最后敲 `puts $score` 回车。有了输入，就能做出完整的交互程序。

## rand()：获取随机数 {#rand}

`rand()` 获取 0-1 的随机数（**不可以等于 1**）。可以输入 `expr {rand()}` 进行查看获取的随机数：

:::tclrun
puts [expr {rand()}]
puts [expr {int(rand()*100)}]   ;# 0-99 的整数随机数（多跑几次看变化）
:::

## 综合例子：猜拳游戏（课件原题） {#rps}

把 gets 输入、rand() 随机数、if/elseif/else 全部串起来——你出拳，电脑随机出拳，程序判胜负：

:::fig tcl-01 | 猜拳游戏完整代码（课件截图）
:::

代码思路：

1. `set choices {shitou jianDao bu}`——三种出拳（0 石头 / 1 剪刀 / 2 布）；
2. `expr {int(rand() * [llength $choices])}`——电脑随机选一个；
3. `gets stdin ply_ch`——玩家输入 0/1/2；
4. `if` 三分支：相同平局 → 玩家赢 → 玩家输。

在练习台里试玩（把出拳数字敲进输入行，多玩几轮）：

:::tclrun
set choices {shitou jianDao bu}
set com_num [expr {int(rand() * [llength $choices])}]
set com_ck [lindex $choices $com_num]
puts "please enter your choices shitou(0) jianDao(1) bu(2)"
gets stdin ply_ch
set ply_ck [lindex $choices $ply_ch]
puts "Computer:$com_ck"
puts "You:$ply_ck"
if {$com_num == $ply_ch} {
    puts "Draw!"
} elseif {($ply_ch == 0 && $com_num == 1) || ($ply_ch == 1 && $com_num == 2) || ($ply_ch == 2 && $com_num == 0)} {
    puts "You win!"
} else {
    puts "You lose!"
}
;# 输入行敲 0 / 1 / 2 之一，回车运行。多玩几局看结果变化
:::

## 动手练 {#lab}

:::lab 文档原题：猜数字游戏
思路：用 `expr {int(rand()*100)}` 生成一个 0-99 的随机数，`gets stdin` 循环读用户猜的数，`if` 判断大了/小了/对了。（第 8 讲学了 while 再回来做，参考答案见下。）
:::

:::tclrun
;# 猜数字参考实现：练习台里把每次猜测依次敲进输入行（如 50 回车 75 回车……）
set answer [expr {int(rand()*100)}]
set times 0
while {1} {
    incr times
    puts "第 $times 次猜：请输入 0-99 的数字"
    gets stdin guess
    if {[string length $guess] == 0} {
        puts "输入用完了，答案是 $answer"
        break
    }
    if {$guess == $answer} {
        puts "猜对了！答案是 $answer"
        break
    } elseif {$guess > $answer} {
        puts "大了"
    } else {
        puts "小了"
    }
}
:::

gets stdin 相当于 Python 的什么？| input()，从标准输入读一行存进变量。
rand() 的取值范围？| 0 到 1 之间、不等于 1。配 int() 用：`expr {int(rand()*100)}` 生成 0-99 整数。

:::
