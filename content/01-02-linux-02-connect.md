## 2. 目录的结构 {#tree}

### 系统级目录

| 目录 | 用途 |
|---|---|
| `/` | **根目录**，所有的文件都存放在根目录下 |
| `/bin` | 命令的存放位置 |
| `/dev` | 一些设备的配置文件 |
| `/etc` | 存放网络的相关配置文件，密码、防火墙配置、端口等 |
| `/home` | **家目录**，所有普通用户的家目录（或写作 `~`） |
| `/opt` | 存放一些安装的软件 |
| `/root` | **超级管理员**的家目录 |
| `.` | 当前目录 |
| `..` | 当前目录的上一级目录 |

### 工作级的目录

每个人会有一个自己的盘（工作区），例如：

```
/P3_A/CPU/zhangshan/
```

PR-ECO 会起很多 run（运行目录），所以每个人有独立的工作目录非常重要——互不干扰。

## 3. 通过颜色区分文件类型 {#color}

| 颜色 | 含义 |
|---|---|
| 蓝色 | 目录 |
| 白色 | 普通文本文件 |
| 绿色 | 一般是加了可执行权限的文件 |
| 红色 | 压缩、打包之后的文件 |
| 浅蓝 | 链接文件 |

:::note 先混个眼熟
下一课开始正式敲命令。ls 出来一大片颜色时，你就能一眼分清哪些是目录、哪些是文件、哪些是压缩包。
:::

存放安装软件的目录是？| /opt。
蓝色的文件名代表什么？| 目录；绿色一般是加了可执行权限的文件；红色是压缩/打包文件；浅蓝是链接文件。
