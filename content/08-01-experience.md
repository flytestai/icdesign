## 十二个坑 {#twelve}

### 1. 不存盘就跑下一步
`.enc` / `save_block` 没做，崩溃或想回退时从零开始。**每阶段必存，文件名带序号。**

### 2. 用 `rm -rf` 清目录
`rm -rf run/*` 手滑成 `rm -rf run /*`，删的是根目录。**先 `ls` 再删，变量加引号。**

### 3. 约束没读对就开始优化
时钟周期写错、false path 漏设、库 corner 用错。跑 4 小时才发现方向全错。**先 `report_clocks` + `check_timing`。**

### 4. 利用率定太高
0.85 看起来很"省面积"，实际布不通。**第一版 0.60~0.65，跑完看拥塞再调。**

### 5. 宏单元通道没算
默认间距摆下去，布线阶段拥塞爆炸。**按出线数算通道（03-03），留 halo。**

### 6. 跳过 CTS 直接布线
hold 违例 −10ns 级别，怎么修都修不完。**CTS 是 hold 收敛的前提。**

### 7. 先修 hold 再修 setup
修 setup 时插的 buffer 会把 hold 又搞坏，来回两三轮。**顺序：setup → hold → 复验。**

### 8. 网表和 SPEF 不同版本
PT 报找不到引脚，或时序离谱。**同一条命令同时导出，文件名带同一时间戳。**

### 9. LVT 用太多
时序一好就全换 LVT，漏电涨 3~5 倍，功耗签核被打回。**LVT 占比 10%~20%。**

### 10. DRC 卡在几百条就乱调参数
剩下的是孤例，批量调参数只会引入新问题。**分类统计 + 按区域聚类，一类一类修。**

### 11. 报错只看最后一行
`OPT-041` 那一行是结果，真正的病因在上五行（`NEX-018`）。**往上翻，找第一条错误。**

### 12. 改完不记录
"我记得改过 utilization" —— 改到多少？哪一版？没有记录就等于没改过。**每次运行写一个 `README.txt`：改了什么、为什么、结果如何。**

:::term Regression | 回归
把一整套流程脚本化，每次改动后全量重跑一遍，对比指标有没有变差。

这是把"手工调参"变成"工程"的关键手段：**没有回归，你永远不知道这次改动是变好还是变坏。**
:::

## 排错方法论 {#debug}

遇到问题，按这个顺序走，不要跳：

1. **看第一条错误**，不看最后一条。
2. **确认输入**：网表、库、约束、脚本版本对不对。
3. **缩小范围**：能不能用更小的设计复现？（counter 能不能跑？）
4. **对比基线**：和上一次成功的运行比，改了什么？
5. **二分手动验证**：把流程切一半跑（只到 place），看问题在哪一半出现。

:::scene 一个真实的排错过程
现象：ICC2 `place_opt` 报 `OPT-041`。

- 第 1 步：往上翻日志，发现 `NEX-018 no valid parasitic`。
- 第 2 步：确认输入 —— NDM 有 timing view，但没读 TLU+。
- 第 3 步：缩小范围 —— 用 counter 小设计试，同样报错，说明是环境问题不是设计问题。
- 第 4 步：对比基线 —— 上一版流程没读寄生，也能跑（因为没开 place_opt）。
- 第 5 步：补 `read_parasitic_tech` + `set_parasitic_parameters`，通过。

**整个过程 40 分钟，其中 30 分钟花在"往上翻日志"和"缩小范围"。**
:::

## Review 该准备什么 {#review}

被 review 时，组长通常按这个顺序问：

| 顺序 | 问题 | 你要能给出 |
|---|---|---|
| 1 | 设计规模？ | 单元数、面积、利用率、macro 数量 |
| 2 | 现在什么状态？ | 做到哪个阶段，卡在哪 |
| 3 | 关键指标？ | WNS/TNS、DRC 数、面积、功耗 |
| 4 | 最大的风险？ | 哪条路径最紧、哪个区域最拥塞 |
| 5 | 下一步计划？ | 具体动作 + 预计耗时 |

**准备一页纸**：规模、状态、指标、风险、计划。比讲半小时流程有用。

## 交接的习惯 {#handoff}

给别人交东西时，至少包含：

1. **怎么跑**：一条命令，或者一个 `run.sh`。
2. **输入在哪**：网表、库、约束的路径。
3. **产物在哪**：报告、def、gds。
4. **已知问题**：哪些违例是已知的、为什么可以接受。
5. **上次运行结果**：关键指标数字。

:::tip 交接文档模板
```markdown
# ipa_top PR 交接
- 脚本: pnr/scripts/01~07_*.tcl
- 运行: cd pnr && ./run_all.sh
- 输入: syn/netlist/ipa_top.v, constraints/ipa.sdc
- 结果: 单元 12026, 面积 222.5x222.2um, WNS +1.00ns, DRC 0
- 已知问题: 3 条 max_transition 违例已 waiver（原因见 waiver.txt）
- 复现: run/20261122_1400/
```
**五行字，能省对方两小时。**
:::
