## 为什么后端也要懂电路 {#why}

:::goal 能画出 NMOS 的三个极并说出栅极怎么控制导通；能解释"28nm 指的是沟道长度"以及短沟道效应为什么会漏电；能说出 FinFET 相比平面 MOS 的关键差别；能用与或非门推出半加器/全加器；能说出 CPU 由哪几类模块组成、后端通常负责其中哪一部分。
:::

你每天在做的事，是把几百万个晶体管摆到硅片上、用金属线连起来、让它们在正确的时刻翻转。如果不知道这些器件是什么、为什么这样连，你看到的就是一堆缩写和坐标。

这一课不要求你会设计电路，只要求你**能对上号**：看到 `NAND2_X1` 知道它是"两个输入做与再取反"，看到 `DFF` 知道它是"存 1 bit 的触发器"，看到"28nm 工艺"知道那个 28 指的是什么。

## 晶体管：一个能被电压控制的开关 {#transistor}

:::term 晶体管 | transistor / MOSFET
半导体芯片里最基础的单元，一个**用栅极电压控制电流通断**的器件。芯片里几百万、几十亿个这样的开关，组合出全部功能。
:::

以 **NMOS** 为例，它有三个极：

```
        栅极 Gate（控制端：加电压）
             │
      ┌──────┴──────┐
      │   ~~~~~~~   │  ← 沟道：栅极下方、连接源漏的通道
  ────┤             ├────
  源极 Source    漏极 Drain
 （电流入口）    （电流出口）
```

- **源极（Source）**：电流入口；
- **漏极（Drain）**：电流出口；
- **栅极（Gate）**：控制端。**不加电压时沟道是断的，电流过不去；加上电压后电子被吸附到沟道里，形成导电通道，电流就能通过**。

:::term 沟道 | channel
栅极下方连接源极与漏极的那条通道。它的**长度**决定了器件有多快、多小——这就是"工艺节点"的来源。
:::

## "28nm"到底指什么 {#node}

:::tip 工艺节点 = 沟道长度
所谓 28nm、16nm、7nm 工艺，指的是**沟道（栅极下方那条通道）的长度**，不是芯片面积、也不是线宽。

工艺越先进 → 沟道越短 → 晶体管占的面积越小 → 同样面积能塞更多器件。
:::

但沟道不能无限缩短，因为会出现**短沟道效应**：

:::term 短沟道效应 | short channel effect
沟道太短时，**源极和漏极离得太近**。即使栅极不加电压，电子也会从源极直接"溜"到漏极（电子逃逸），形成关不断的漏电流。
:::

后果很严重：器件关不掉 → 静态功耗暴涨 → 芯片发烫、待机功耗超标。**这是工艺走到 28nm 以下时最头疼的物理问题。**

## FinFET：把沟道立起来，三面包裹 {#finfet}

:::term FinFET | 鳍式场效应晶体管
把硅的沟道**竖起来做成鱼鳍状**，让栅极从**顶部、左侧、右侧三面**包住沟道的器件结构。
:::

```
   平面 MOS（一面控制）          FinFET（三面控制）
      ┌─────────┐                  ┌───┐
      │  栅极   │                  │栅 │  ← 顶
  ────┴─────────┴────          ┌───┤   ├───┐
     ▔▔▔▔▔▔▔▔▔▔▔               │栅 │鳍 │栅 │ ← 左右
      沟道（平躺）              └───┴───┴───┘
```

关键差别就一句话：**接触面积变大，栅极对沟道的控制力变强，电子逃逸被抑制住**。

工程上的分界（文档给的）：

| 工艺 | 器件类型 |
|---|---|
| 28nm 及以上 | 平面 MOS 管 |
| 16nm / 12nm / 7nm 及以下 | **FinFET 鳍式晶体管** |

所以你在招聘里看到"做过 16nm FinFET 项目"，说的是他用过这一代器件和配套的库/规则，而不是他会设计器件。

## 逻辑门：几个晶体管搭出一个功能 {#gate}

:::term 逻辑门 | logic gate
由多个晶体管组合而成、实现一个基本逻辑功能的电路单元。芯片里所有复杂功能，最终都是它们的组合。
:::

先记住电平约定：**1 = 高电平（VDD），0 = 低电平（VSS/地）**。

| 门 | 英文 | 规则 | 一句话 |
|---|---|---|---|
| 与门 | **AND** | 全 1 才出 1 | 所有条件都满足才成立 |
| 或门 | **OR** | 有 1 就出 1 | 任一条件满足就成立 |
| 非门 | **NOT** / INV | 输出与输入相反 | 取反 |
| 与非门 | **NAND** | 与之后取反 | 最常用，面积小 |
| 或非门 | **NOR** | 或之后取反 | |
| 异或门 | **XOR** | 不同出 1，相同出 0 | 加法器的"和" |
| 缓冲器 | **BUF** | 输出等于输入 | 用来增强驱动、整形 |

:::tip 为什么 NAND 比 AND 更常用
同样功能，NAND 用更少的晶体管、面积更小、速度更快。所以标准单元库里 NAND2_X1 这类单元满天飞，而纯 AND 门反而不多——**这是"逻辑等价但物理代价不同"的第一个例子**，后面布局布线里到处都是这种取舍。
:::

## 二进制与加法器：0 和 1 怎么算加法 {#binary}

二进制**逢二进一**，第 n 位（从 0 数）的权重是 2ⁿ：

```
二进制 1 1 1 1
权重   8 4 2 1   →  8+4+2+1 = 15（十进制）
```

用门电路实现加法，分两步走：

**半加器（half adder）**：两个 1 bit 输入，输出"和"与"进位"。

```
A ──┐
    XOR ──→ Sum    （异或：不同出 1，正好是"和"）
B ──┘
A ──┐
    AND ──→ Carry  （与：两个都是 1 才进位）
B ──┘
```

**全加器（full adder）**：在半加器基础上多一个**进位输入（Cin）**，因为多位相加时低位会进位上来。把 N 个全加器串起来（低位进位接高位进位输入），就得到 N 位加法器。

:::tip 这条链要记住
**晶体管 → 逻辑门 → 功能模块（加法器/比较器/多路选择器）→ CPU**

后端看到的所有 instance，都落在这条链的中间层：你摆的是"逻辑门级的标准单元"，服务的是"模块级的功能"。
:::

## 从加法器到 CPU：模块级视角 {#cpu}

CPU 由几类模块组成（文档列举的）：

| 模块 | 作用 |
|---|---|
| **ALU**（算术逻辑单元） | 做加减、与或、比较等运算 |
| **Register**（寄存器） | 存中间结果，由大量 DFF 组成 |
| **控制单元**（Control） | 产生控制信号，指挥各模块按节拍动作 |
| **高速存储**（Cache/SRAM） | 缓存数据，通常是硬 macro |
| **总线接口**（Bus/IO） | 与外部交换数据 |

:::term DFF | D 触发器
D Flip-Flop，最基本的存储单元，**在时钟沿把输入 D 搬到输出 Q**，其余时间保持不变。它是时序分析的分界线：一条路径从某个 DFF 的 Q 出发，到另一个 DFF 的 D 结束。
:::

**对后端的意义**：一个 CPU 项目动辄几千万门，不可能一个人做。**你会被分配其中一两个模块（block）**，比如 ALU 或某个 Cache 控制逻辑——这也是为什么后面所有课程都在讲"模块级（block）设计"。你做的那一块，就是一个有边界、有端口的独立小芯片。

## 术语与英文名：这是硬门槛 {#terms}

文档里反复强调要**背术语**，因为课程里 80%~90% 的内容都由这些名词承载。最基础的一批：

| 缩写 | 全称 | 中文 |
|---|---|---|
| MOS / NMOS / PMOS | Metal-Oxide-Semiconductor | 金属氧化物半导体 / N 型 / P 型 |
| FinFET | Fin Field-Effect Transistor | 鳍式场效应晶体管 |
| AND / OR / NOT | — | 与 / 或 / 非 |
| NAND / NOR / XOR | — | 与非 / 或非 / 异或 |
| INV / BUF | Inverter / Buffer | 反相器 / 缓冲器 |
| ALU | Arithmetic Logic Unit | 算术逻辑单元 |
| DFF | D Flip-Flop | D 触发器 |
| SDC | Synopsys Design Constraints | 时序约束文件（后面专门讲） |
| CDC | Clock Domain Crossing | 跨时钟域（前端关注，后端要配合约束） |

:::pitfall 把"工艺节点"当成实际尺寸
**现象**：算面积时把 28nm 当成线宽，或者以为 7nm 芯片的线真的只有 7nm 宽。

**事实**：28nm 指沟道长度，是**器件参数**；金属线宽、间距要看 tech lef（28nm 工艺的 M1 线宽约 0.07μm 量级）。而且从 22nm 往下，节点名已经更多是"代际代号"，不再等于任何单一物理尺寸。

**记住**：**节点名是代际，物理尺寸一律查 lef/lib。**
:::

## 动手：把逻辑门和二进制跑一遍 {#lab}

下面的练习台可以直接运行，也可以把数字改掉（0 改 1）看结果怎么变：

:::tclrun
# 与门：全 1 才输出 1
puts "1 AND 1 = [expr {1 && 1}]"
puts "1 AND 0 = [expr {1 && 0}]"

# 或门：有 1 就出 1
puts "1 OR 0 = [expr {1 || 0}]"

# 非门：取反
puts "NOT 1 = [expr {!1}]"

# 异或门：不同出 1（这就是半加器的"和"）
puts "1 XOR 0 = [expr {1 ^ 0}]"
puts "1 XOR 1 = [expr {1 ^ 1}]"

# 半加器：1+1 → 和 0、进位 1
puts "1+1 -> sum=[expr {1 ^ 1}] carry=[expr {1 & 1}]"

# 二进制 1111 = 8+4+2+1 = 15
puts "1111(2) = [expr {8 + 4 + 2 + 1}]"
:::

:::lab 手算 + 对号
1. 手算二进制 `1011` 的十进制值，再用练习台验算；
2. 说出 `1 XOR 1` 为什么是 0、`1 AND 1` 为什么是 1；
3. 在纸上画一个 NMOS，标出源极、漏极、栅极，并写出"栅极加压/不加压"两种情况的沟道状态；
4. 用一句话解释：为什么 16nm 以下要用 FinFET。

验收标准：四题都能不看课回答出来，且能说清"28nm 指的是沟道长度"。
:::

:::quiz
晶体管三个极分别是什么？栅极怎么控制电流？| 源极（电流入口）、漏极（电流出口）、栅极（控制端）。栅极不加电压时沟道阻断，加电压后电子被吸附到沟道，形成导电通道。
"28nm 工艺"里的 28nm 指什么？| 指沟道长度（栅极下方连接源漏的通道长度），不是线宽也不是芯片面积。
短沟道效应是什么？为什么可怕？| 沟道太短导致源漏太近，即使栅极不加电压电子也会从源极溜到漏极，形成关不断的漏电流；后果是静态功耗暴涨、芯片发烫。
FinFET 相比平面 MOS 的关键差别是什么？| 把沟道竖起来做成鳍状，栅极从顶面 + 左右两侧三面包裹，接触面积更大、控制力更强，从而抑制短沟道漏电。
半加器由哪两个门组成？各负责什么？| 异或门负责求和（输入不同输出 1），与门负责进位（两个都为 1 才进位）。
全加器比半加器多了什么？| 多一个进位输入 Cin，用于接收低位来的进位；多个全加器串联构成多位加法器。
CPU 通常由哪几类模块组成？| ALU（运算）、寄存器（存储中间结果）、控制单元、高速存储（Cache/SRAM）、总线接口。
为什么 NAND 比 AND 更常用？| 同样功能下 NAND 用的晶体管更少、面积更小、速度更快，所以标准单元库里 NAND 单元最多。
:::
