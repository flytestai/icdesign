## 简历：一行字要回答三个问题 {#resume}

后端简历最容易犯的错：写成流程说明书。

```
❌ 参与 IPA 项目后端设计，使用 Innovus 完成 floorplan、placement、CTS、routing。
```

这句话的问题：**没有规模、没有指标、没有你的贡献。**

改成：

```
✅ IPA 图像加速器（9390 单元 / 6 个 SRAM / 40nm）后端实现：
   floorplan 阶段重排宏单元通道，使布线 DRC 从 6000 降至 0；
   全流程 21.7 分钟收敛，WNS +1.00ns，面积 222.5×222.2µm。
```

公式：

```
做了什么（设计 + 规模 + 工艺） + 遇到了什么问题 + 你做了什么动作 + 量化结果
```

:::term STAR | 情境-任务-行动-结果
Situation / Task / Action / Result。面试答题和写简历都用这个结构。

关键在 A 和 R：**你具体做了什么动作，带来了什么可量化的变化。**
:::

## 项目描述模板 {#project}

```markdown
### IPA 图像加速器后端实现（40nm, 9390 cells）
- 输入：RTL 综合网表 + SDC 约束 + Nangate45/TSMC40 库
- 我做的事：
  1. Floorplan：6 个 SRAM 靠边对齐，按出线数算通道宽度（20µm），设 halo
  2. 电源：ring + stripe 覆盖，via 阵列补齐，IR 预估 3.8%
  3. 布局与 CTS：pin_density_aware 开启，skew 目标 80ps，实际 62ps
  4. 布线：route_auto + route_opt + incremental detail
- 结果：DRC 0、open net 0、WNS +1.00ns、hold −0.07ns、FM 2560/2560 等价
- 复盘：第一版通道只有 10µm，DRC 6000；改到 20µm 后首轮即 0
```

**最后一行"复盘"最有价值**：它证明你不是照流程点按钮，而是理解了因果。

## 20 道高频面试题 {#questions}

### 概念类

| 问题 | 考点 | 答法要点 |
|---|---|---|
| setup 和 hold 的区别 | 时序基础 | setup 看下一个时钟沿之前数据是否稳定；hold 看当前沿之后数据是否保持 |
| 为什么降频救不了 hold | 公式理解 | hold 公式里没有时钟周期，只和逻辑延迟、T_hold、skew 有关 |
| 什么是 skew，越大越好还是越小越好 | 时钟树 | 到达时间差；不是越小越好，要留 useful skew 空间，且过小会插过多 buffer |
| 利用率定多少合适 | floorplan | 0.6~0.75；过高拥塞，过低浪费面积 |
| 宏单元怎么摆 | floorplan | 靠边、对齐、pin 朝内、留通道（按出线数算）、加 halo |
| 为什么必须做 CTS | 时钟树 | 不建树 skew 巨大，hold 无法收敛 |
| IR drop 分几种 | 功耗完整性 | 静态（平均电流，3~5%）和动态（瞬时电流，8~10%） |

### 工具类

| 问题 | 考点 | 答法要点 |
|---|---|---|
| Innovus 和 ICC2 的区别 | 工具广度 | 数据组织不同（.enc vs NDM+block），命令可一一对应，方法论相同 |
| NDM 里缺时序视图会怎样 | ICC2 | place_opt/clock_opt 起不来，报 OPT-041 |
| 怎么修 setup 违例 | 优化手段 | upsize、换 LVT、插 buffer、挪位置、useful skew、降频（最后） |
| 怎么修 hold 违例 | 优化手段 | 插延迟单元、调 skew、删多余 buffer |
| PT 和 PR 工具自带 STA 的差别 | 签核 | 独立性、精度、约束解析严格程度、行业认可 |
| 怎么做 ECO | 流程 | PT 出 ECO 清单，PR 读入执行，重新导出网表/SPEF 复算 |

### 排错类

| 问题 | 考点 | 答法要点 |
|---|---|---|
| place_opt 报 OPT-041 怎么查 | 排错 | 往上翻日志找第一条错误，常见是缺寄生模型（NEX-018） |
| DRC 清不干净怎么办 | 排错 | 先看分布，判断是布局问题还是孤例；分类统计 + 区域聚类 |
| 时序突然变差怎么定位 | 排错 | 对比基线、看约束是否变、看库 corner、看是否换了版本 |
| 报 command not found | 环境 | which、echo $PATH、确认 shell（bash 用 export，tcsh 用 setenv） |
| 网表和 SPEF 不匹配的现象 | 流程 | 报找不到引脚、时序不合理；必须同一次运行同时导出 |

## 模拟面试怎么练 {#mock}

三步，每步 20 分钟：

1. **自我介绍（2 分钟）**：一句话背景 + 一个项目 + 一个亮点。不要从大学讲起。
2. **项目深挖（10 分钟）**：对方会问"为什么这么做""如果改条件会怎样"。**答不上来就说"这块我当时没深入，我的理解是…"，别编。**
3. **基础题抽查（8 分钟）**：上面 20 题随机抽 5 道。

:::pitfall 面试时说"我们团队"
面试官只关心**你**做了什么。

错误："我们做了 floorplan 优化。"
正确："我负责 floorplan，具体做了三件事：算通道宽度、调宏单元朝向、加 halo。结果 DRC 从 6000 降到 0。"

**把"我们"换成"我"，把动作说具体。**
:::

## 投递与谈薪 {#apply}

| 渠道 | 特点 |
|---|---|
| 内推 | 命中率最高，优先找师兄师姐、前同事 |
| 招聘网站 | 量大但竞争激烈，简历要针对 JD 改关键词 |
| 公司官网 | 大厂必投，流程正规 |
| 猎头 | 3 年以上经验更有效 |

谈薪三条：

1. **先问范围**："这个岗位的预算区间是多少？"（很多 HR 会直接给）
2. **报区间不报单点**："期望 25~30K"，给自己留空间。
3. **拿总包比**：月薪 × 几个月 + 签字费 + 股票，别只比月薪。

:::check
- 能用公式写出自己的项目描述（规模 + 问题 + 动作 + 量化结果）
- 20 道高频题至少能答出 15 道
- 知道模拟面试的三段结构
- 会把"我们"改成"我"，把动作说具体
:::

:::quiz
简历里的项目描述应该包含哪四要素？|设计规模与工艺、遇到的问题、你做的具体动作、可量化的结果。
"为什么降频救不了 hold" 该怎么答？|hold 公式是 T_logic ≥ T_hold + skew，不含时钟周期，所以降频无效。
面试官问"最大的难点是什么"，怎么答才有说服力？|讲一个具体问题：现象、你怎么定位、做了什么、结果如何（最好带数字）。
为什么简历最后要写"复盘"？|证明你理解因果而不是照流程操作，能说出"第一版为什么错、改了什么就好了"。
谈薪时为什么要报区间？|给自己留谈判空间，也避免因单点报价过低或过高直接出局。
:::
