## 定义变量：set 命令 {#set}

:::goal 会用 set 定义三种类型变量；建立"名字绑一个值"的心智模型；说清 {} "" [] 三种符号各自做什么；会用 ${} 调用特殊变量名；会用字典写法装多份信息。
:::

**语法：`set 变量名 变量值`**

:::note 心智模型（文档原话）
变量就是一个名字绑一个值——**名字给你看，值给机器用**。比如定义一个人 person，名字叫张三：`person` 是我们（人）用的名字，"张三"是机器存的值。
:::

**示例**：

:::tclrun
set name "Zhang San"   ;# 字符串变量（双引号可保留空格）
set age 25             ;# 数值变量
set score 98.5         ;# 浮点型变量
puts "姓名：$name，年龄：$age，成绩：$score"
puts "$name $age"       ;# 打印多个变量
puts "age=$age , name=$name"
:::

**命名规则**：变量名由字母、数字、下划线组成，建议见名知意（如 `age`、`user_name`），避免特殊字符（下划线除外）。

## TCL 的三种"替换"——一句话原理（文档原文） {#substitution}

:::note 一句话原理
`{}`（不读变量）和 `""`（读变量）是同一类——**分组**（把空格/换行粘成一个词），区别只在于"里面做不做替换"；`[]` 完全是另一类——**替换**（先跑命令，用结果把自己顶掉）。
:::

| 符号 | 叫什么 | 干什么 | Python 类比 |
|---|---|---|---|
| `$变量名` | 变量替换 | 把变量的值取出来放进去 | 直接写变量名 |
| `[命令]` | 命令替换 | 先执行命令，用结果替换整个 `[...]` | 表达式的返回值 |
| `{...}` | 分组 | 把一段内容"原样打包"，不读变量 | 原始字符串 `r"..."` |
| `"..."` | 分组 | 打包，但**会**做变量替换 | f-string |

**例子感受一下**：

:::tclrun
set name "Tom"
puts "hello $name"    ;# 输出：hello Tom（"" 里读了变量）
puts {hello $name}    ;# 输出：hello $name（{} 里原样输出）
set x [expr {1 + 2}]  ;# [] 先算出 3，再赋给 x
puts $x
:::

读一遍输出，确认你能解释每一行为什么长这样——这一讲就算学通了。

## 调用变量：$变量名 {#dollar}

在字符串或命令里写 `$name` 就能取到变量的值。

## 特殊变量名：用 ${} 包裹（很少用，但要会） {#special}

当变量名里含特殊字符（如 `.`、`-`）时，定义照常，**调用必须用 `${变量名}` 包裹**，否则 TCL 解析失败：

:::tclrun
set a.1 100      ;# 变量名含小数点，特殊定义
set b-2 "test"   ;# 变量名含减号，特殊定义
puts ${a.1}      ;# 正确调用，输出：100
puts ${b-2}      ;# 正确调用，输出：test
:::

看一眼错误示范（练习台里跑跑看，报错也是真实的）：

```tcl
puts $a.1
;# 错误！TCL 会解析为变量 a + 字符串 ".1"
;# 报错：can't read "a": no such variable
```

:::pitfall $a.1 不报语法错，但读的是另一个变量
`$a.1` 不读 `a.1`，而是读变量 `a` 再拼上字符串 `.1`。变量 `a` 不存在，所以报 `can't read "a": no such variable`。看到这个报错，先想想是不是变量名里有特殊字符没用 `${}`。
:::

## set 一次只能定义一个变量（想定义"多个"用字典） {#multi}

TCL 的 `set` **不支持一次定义多个变量**。如果想要"一个名字装多份信息"，可以借助字典写法：

:::tclrun
set info {age 20 name zhangsan}
puts [dict get $info age]     ;# 取出 20
puts [dict get $info name]    ;# 取出 zhangsan
:::

原理：`{age 20 name zhangsan}` 是一个"键 值 键 值"交替排列的列表，`dict get` 按键取值。（字典的完整讲法在第 4 讲数组之后。）

## 动手练 {#lab}

:::lab 本讲练习（2 题）
1. 定义变量 `user_name`、`age`，用一条 `puts` 同时打印它们。
2. 解释为什么 `puts {age=$age}` 不会输出变量值。
:::

:::quiz
练习 1 的写法？| `set user_name "Tom"`、`set age 25`，然后 `puts "user=$user_name age=$age"`。
练习 2 的答案？| 因为 `{}` 是"不读变量"的分组，里面的 `$age` 不会被替换，会原样输出 `age=$age`。想读变量改用双引号 `"age=$age"`。
`[expr {1 + 2}]` 里的方括号是什么机制？| 命令替换：先执行里面的命令，用结果替换整个 [...]。
:::

- 能不看示例写出 set + puts 的定义与打印
- 能解释 {} "" [] 三种符号的区别
- 变量名含特殊字符时知道用 ${} 调用
:::
