## 1. sed {#sed}

:::goal sed 的打印/新增/删除/替换四种操作全部上手；awk 三段式框架和内置变量记牢，能独立完成列提取练习；会用 gvimdiff 对比文件。
:::

:::pitfall 所有操作不加 -i 都不会修改原文件
sed 默认只把处理结果打印到屏幕，原文件不动；要真正写回文件需要加 -i。先用打印模式确认效果，再决定是否加 -i。
:::

:::fig linux-22 | sed 常用操作速查
:::

### 1、打印指定的行

```
sed -n '2p'   文件     # 打印第 2 行内容
sed -n '3,5p' 文件     # 打印第 3 行到第 5 行内容
```

### 2、在指定行新增内容

```
sed '2a 内容' 文件     # 在第 2 行后面追加内容
sed '3i 内容' 文件     # 在第 3 行前面插入内容
```

### 3、删除指定行内容

```
sed '3d'    文件      # 删除第 3 行
sed '2,5d'  文件      # 删除第 2 行到第 5 行内容
```

### 4、替换指定的内容

```
sed 's/old/new/g'   文件   # 替换所有行的某些关键字
sed '3s/old/new/g'  文件   # 只替换第 3 行的某些关键字
sed '2c 内容'       文件   # 替换第 2 行整行
sed '2,5c 内容'     文件   # 替换第 2 行到第 5 行
```

## 2. awk {#awk}

**awk 实操热身**：

1、进入家目录；2、创建文件 test_awk.txt，写入以下内容：

```
aaaa bbbb cccc
1111;2222;3333
qqqq:wwww:eeee
```

热身问题：3、取出 cccc；4、取出 wwww；5、打印第 2 行整行内容；6、打印第三行的第 1 列和第 3 列；7、打印第 2 列大于 1200 且第三列小于 4000 的行。

### 核心语法结构

awk 三部分核心框架，可单独/组合使用：

```
awk 'BEGIN{初始化操作} 条件{处理动作} END{收尾操作}' 文件名
```

- **BEGIN**：执行处理前运行（仅 1 次，比如定义变量）；
- **中间块**：逐行处理文件，满足条件才执行动作（最常用）；
- **END**：所有行处理完后运行（仅 1 次，比如统计结果）。

### 必记内置变量

| 变量 | 含义 |
|---|---|
| `NR` | 当前处理的行号 |
| `NF` | 当前行的字段总数（一行 3 列则 NF=3） |
| `$NF` | 直接取最后一列 |
| `$0` | 当前整行内容 |
| `$n` | 第 n 个字段（$1 第 1 列，$NF 最后 1 列） |
| `FS` | 字段分隔符（等价于 -F 参数） |

### 常用操作符

- 比较：`>` `<` `>=` `<=` `==` `!=`（字符串用双引号包起来，如 `$1=="root"`）
- 逻辑：`&&`（且）　`||`（或）　`!`（非）
- 匹配：`/字符串/`（包含该字符串），`!/字符串/`（不包含）

### 常用函数

**gsub("旧","新")**：全行替换指定内容。

```
awk  -F ':'  'NR==2{print, gsub(old, new)}'  文件
```

:::fig linux-25 | gsub 替换实操
:::

**substr($1,1,3)**：截取 $1 的第 1 个字符起共 3 位。

```
awk -F ':'  '{print substr($1, 1, 3)}'  文件
```

:::fig linux-26 | substr 截取实操
:::

**length()**：取字符长度。

```
awk -F ':'  '{print length()}'           文件    # 打印每一行的长度
awk -F ':'  '{print length($1), $2}'     文件    # 打印第一列、第二列的长度
```

:::fig linux-27 | length 函数实操
:::

### 实用实例

```
awk '{print $1}'  file.txt                    # 打印文件第 1 列
awk '{print $1, $3}'  file.txt                # 打印第 1、3 列（空格分隔）
awk '{print $2}'  file.txt | sort -u          # 打印第 2 列且去重
awk '$3>100 {print $0}'  file.txt             # 按条件筛选（第 3 列 > 100 才打印）
awk '$1=="root" && $2>50 {print $0}'  file.txt    # 多条件筛选
awk 'END{print NR}'  file.txt                 # 统计文件行数
awk '/test/ {count++} END{print count}'  file.txt # 统计符合条件的行数（第 4 列包含 test）
awk -F ',' '{print $2}'  file.csv             # 自定义分隔符（逗号，取第 2 列）
awk 'NR==2{print $3}'  file                   # 输出指定行指定列
awk 'NR==3{print $0}'  file                   # 输出指定行
```

## 3. gvim 常用命令 {#gvim}

gvim 和 vim 功能完全一致，多了 GUI 界面。下面几张表是**日常后端工作真正高频**的命令——每个都动手敲一遍，形成肌肉记忆。

### 3.1 常用设置（:set 系列）

```
:set nu      显示行号          :set nonu   取消行号
:set wrap    分行显示          :set ic     搜索忽略大小写
:set noic    搜索区分大小写
:set paste   粘贴模式（防止从别处粘代码时自动缩进错乱，粘完 :set nopaste 恢复）
:set noh     取消搜索高亮
```

### 3.2 光标移动

| 按键 | 作用 |
|---|---|
| `h` `j` `k` `l` | 左 下 上 右（手不离主键区的移动四键） |
| `0` / `$` | 跳到**行首** / **行尾** |
| `w` / `b` | 下一个 / 上一个**单词**开头 |
| `gg` / `G` | 文件**第一行** / **最后一行** |
| `:10` | 跳转到第 10 行（配合 `:set nu` 使用） |

### 3.3 编辑操作（效率核心）

| 按键 | 作用 |
|---|---|
| `yy` / `dd` | 复制一行 / 剪切（删除）一行 |
| `3yy` / `5dd` | 复制 / 剪切 n 行（数字前缀） |
| `p` / `P` | 粘贴到光标**下方** / **上方** |
| `u` / `ctrl+r` | **撤销** / **重做** |
| `x` | 删除光标处单个字符 |
| `dw` / `d$` | 删除一个单词 / 删到行尾 |
| `ciw` | 删除当前单词并直接进入插入模式（改一个变量名极快） |
| `A` / `I` | 在**行尾** / **行首**进入插入模式 |
| `r` | 替换光标处单个字符 |

:::tip yy → p 的场景
把一行配置复制到另一个 run 目录的脚本里：光标停在该行按 `yy`，切到目标位置按 `p`——比鼠标复制粘贴快得多。
:::

### 3.4 可视模式

| 按键 | 作用 |
|---|---|
| `v` | 字符可视模式（自由选区） |
| `V` | 行可视模式（整行选择，选中后 d 删 / y 复制） |
| `ctrl+v` | 块模式（第 5 课的批量注释用的就是它） |

### 3.5 分屏

| 命令 | 作用 |
|---|---|
| `:sp 文件` | **上下**分屏打开文件 |
| `:vsp 文件` | **左右**分屏打开文件 |
| `ctrl+w` 再按 `w` | 在分屏之间**循环切换** |
| `ctrl+w` + 方向键 | 按方向切换到指定分屏 |
| `:only` | 关闭其它分屏，只保留当前 |

### 3.6 命令行补充

| 命令 | 作用 |
|---|---|
| `:x` | 保存并退出（等价 `:wq`，更快） |
| `:w !sudo tee %` | 打开时忘了加 sudo，仍能以管理员权限保存 |
| `:!命令` | 在 vim 里临时执行 shell 命令（如 `:!ls`） |

### 3.7 配置文件三兄弟（家目录下）

| 文件 | 用途 |
|---|---|
| `.bashrc` | shell 启动配置（alias、环境变量） |
| `.alias` | 快捷指令 |
| `.vimrc` | vim/gvim 启动自动加载的配置 |

**`.vimrc` 常用配置示例**（写进去，每次打开 gvim 自动生效）：

```
set nu           " 显示行号
syntax on        " 语法高亮
set ts=4         " Tab 宽度 4 空格
set expandtab    " Tab 转空格
set autoindent   " 自动缩进
set ic           " 搜索忽略大小写
```

**比较两个文件的不同**：

```
gvimdiff  file1  file2
```

:::fig linux-28 | gvimdiff 对比文件与文件内跳转
:::

**文件内跳转练习**：在家目录下创建 t1 和 t2：

- t1 文件内容：`this is t1 file`，以及 `t2 file path is ''`（用 realpath t2 填入 t2 的绝对路径）；
- t2 文件内容：`this is t2 file`。

用 `g + f` 从 t1 里跳到 t2，`ctrl+o` 返回原文件。

   demo  111  222  333

4、取出第五行的 6
5、取出 222
6、取出 999

:::quiz
sed 怎么才真正修改文件？| 加 -i 选项；不加 -i 只打印结果，原文件不变。
awk 里 $2 和 $NF 的区别？| $2 是第 2 列；$NF 是最后一列（NF 是该行总列数）。
awk 按 : 分割取第 3 列怎么写？| awk -F ':' '{print $3}' 文件。
统计文件行数的 awk 命令？| awk 'END{print NR}' 文件。
gvim 里复制一行再粘贴用什么？| yy 复制当前行，p 粘贴到光标下方；u 撤销、ctrl+r 重做。
:vsp 和 :sp 的区别？| :vsp 左右分屏打开文件，:sp 上下分屏；ctrl+w 再按 w 在分屏间切换。
:::
