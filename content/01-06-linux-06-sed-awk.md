## 1. sed {#sed}

:::goal sed 的打印/新增/删除/替换四种操作全部上手；awk 三段式框架和内置变量记牢，能独立完成列提取练习；会用 gvimdiff 对比文件。
:::

:::pitfall 所有操作不加 -i 都不会修改原文件
sed 默认只把处理结果打印到屏幕，原文件不动；要真正写回文件需要加 -i。先用打印模式确认效果，再决定是否加 -i。
:::

:::fig linux-22 | sed 常用操作速查
:::

### 1、打印指定的行

```
sed -n '2p'   文件     # 打印第 2 行内容
sed -n '3,5p' 文件     # 打印第 3 行到第 5 行内容
```

### 2、在指定行新增内容

```
sed '2a 内容' 文件     # 在第 2 行后面追加内容
sed '3i 内容' 文件     # 在第 3 行前面插入内容
```

### 3、删除指定行内容

```
sed '3d'    文件      # 删除第 3 行
sed '2,5d'  文件      # 删除第 2 行到第 5 行内容
```

### 4、替换指定的内容

```
sed 's/old/new/g'   文件   # 替换所有行的某些关键字
sed '3s/old/new/g'  文件   # 只替换第 3 行的某些关键字
sed '2c 内容'       文件   # 替换第 2 行整行
sed '2,5c 内容'     文件   # 替换第 2 行到第 5 行
```

## 2. awk {#awk}

**awk 实操热身**：

1、进入家目录；2、创建文件 test_awk.txt，写入以下内容：

```
aaaa bbbb cccc
1111;2222;3333
qqqq:wwww:eeee
```

热身问题：3、取出 cccc；4、取出 wwww；5、打印第 2 行整行内容；6、打印第三行的第 1 列和第 3 列；7、打印第 2 列大于 1200 且第三列小于 4000 的行。

### 核心语法结构

awk 三部分核心框架，可单独/组合使用：

```
awk 'BEGIN{初始化操作} 条件{处理动作} END{收尾操作}' 文件名
```

- **BEGIN**：执行处理前运行（仅 1 次，比如定义变量）；
- **中间块**：逐行处理文件，满足条件才执行动作（最常用）；
- **END**：所有行处理完后运行（仅 1 次，比如统计结果）。

### 必记内置变量

| 变量 | 含义 |
|---|---|
| `NR` | 当前处理的行号 |
| `NF` | 当前行的字段总数（一行 3 列则 NF=3） |
| `$NF` | 直接取最后一列 |
| `$0` | 当前整行内容 |
| `$n` | 第 n 个字段（$1 第 1 列，$NF 最后 1 列） |
| `FS` | 字段分隔符（等价于 -F 参数） |

### 常用操作符

- 比较：`>` `<` `>=` `<=` `==` `!=`（字符串用双引号包起来，如 `$1=="root"`）
- 逻辑：`&&`（且）　`||`（或）　`!`（非）
- 匹配：`/字符串/`（包含该字符串），`!/字符串/`（不包含）

### 常用函数

**gsub("旧","新")**：全行替换指定内容。

```
awk  -F ':'  'NR==2{print, gsub(old, new)}'  文件
```

:::fig linux-25 | gsub 替换实操
:::

**substr($1,1,3)**：截取 $1 的第 1 个字符起共 3 位。

```
awk -F ':'  '{print substr($1, 1, 3)}'  文件
```

:::fig linux-26 | substr 截取实操
:::

**length()**：取字符长度。

```
awk -F ':'  '{print length()}'           文件    # 打印每一行的长度
awk -F ':'  '{print length($1), $2}'     文件    # 打印第一列、第二列的长度
```

:::fig linux-27 | length 函数实操
:::

### 实用实例

```
awk '{print $1}'  file.txt                    # 打印文件第 1 列
awk '{print $1, $3}'  file.txt                # 打印第 1、3 列（空格分隔）
awk '{print $2}'  file.txt | sort -u          # 打印第 2 列且去重
awk '$3>100 {print $0}'  file.txt             # 按条件筛选（第 3 列 > 100 才打印）
awk '$1=="root" && $2>50 {print $0}'  file.txt    # 多条件筛选
awk 'END{print NR}'  file.txt                 # 统计文件行数
awk '/test/ {count++} END{print count}'  file.txt # 统计符合条件的行数（第 4 列包含 test）
awk -F ',' '{print $2}'  file.csv             # 自定义分隔符（逗号，取第 2 列）
awk 'NR==2{print $3}'  file                   # 输出指定行指定列
awk 'NR==3{print $0}'  file                   # 输出指定行
```

## 3. gvim {#gvim}

**常用快捷指令**：

```
:set nu    显示行号
:set wrap  分行显示
:set ic    区分大小写
:set noic  不区分大小写
```

**用户家目录下的配置文件**：

- `.alias`——设置快捷指令
- `.bashrc`
- `.vimrc`

**比较两个文件的不同**：

```
gvimdiff  file1  file2
```

:::fig linux-28 | gvimdiff 对比文件与文件内跳转
:::

**文件内跳转练习**：在家目录下创建 t1 和 t2：

- t1 文件内容：`this is t1 file`，以及 `t2 file path is ''`（用 realpath t2 填入 t2 的绝对路径）；
- t2 文件内容：`this is t2 file`。

用 `g + f` 从 t1 里跳到 t2，`ctrl+o` 返回原文件。
