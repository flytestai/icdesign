## 1. 查看文件 {#view}

:::goal 七种方式查看文件；vi 的编辑模式和命令行模式全部记熟；会 diff 对比文件；会配 alias；会用重定向和管道。
:::

```
cat   文件名              # 直接全部输出
cat  -n  文件名           # 查看文件，同时显示行号
zcat  文件               # 查看压缩文本文件
tac   文件名              # 倒着查看文件内容
```

**查看大型文件**：

- `more 文件名`：字母 `b` 往上翻页，字母 `z` 往下翻页，翻到底自动退出，或按 `q` 退出；
- `less 文件名`：和 more 用法一样，但必须按 `q` 才能退出。

**查看文件开头 / 结尾**：

```
head  文件名        # 默认查看前 10 行
head  -20  文件名   # 查看文件前 20 行
tail  文件名        # 默认查看后 10 行
tail  -20  文件名   # 查看文件的后 20 行
```

:::tip 查 log 最常用
`tail -100 xxx.log` 看最新 100 行——跑完仿真/PR 第一件事就是它。
:::

## 2. vi / vim / gvim 编辑文件 {#vi}

- **vi**：查看文件并且可以编辑；
- **vim**：相比 vi 可以做一些高效的配置；
- **gvim**：相比较 vim，多了 gui 界面，功能和 vim 一致（还支持打开压缩文件）。

**vi 的基本用法**：

```
vi  文件名
```

- 文件不存在，会创建——但**不保存就不会真的创建**；
- 如果有这个文件，就会打开显示内容。

### 进入编辑模式（左下角会显示 insert）

| 按键 | 作用 |
|---|---|
| 字母 `a` | 在光标**后面**追加（append 模式） |
| 字母 `i` | 在光标**所在位置**插入（insert） |
| 字母 `o` | **换行**再插入内容 |

按 `esc` 可以退出编辑模式（insert 消失）。

### 命令行模式（按 `:` 进入）

| 命令 | 作用 |
|---|---|
| `:10` | 快速跳转到第 10 行 |
| `:set nu` | 将文件带上行号显示 |
| `:set wrap` | 会换行显示 |
| `:wq` | 保存并退出 |
| `:wq!` | 强制保存 |
| `:q` | 不保存退出 |
| `:q!` | 强制不保存退出 |
| `:set ic` | 搜索的时候忽略大小写 |
| `/关键字` | 向下搜索关键字，`n` 下一个，`shift+n` 上一个 |
| `?关键字` | 向上搜索关键字 |

### 对比两个文件的差异

```
diff       文件1 文件2    # 直接打印不同的内容
zdiff      压缩文件对比    # 支持 zcat 类压缩格式
gvimdiff   文件1 文件2    # 打开两个文件，高亮显示不同的部分
```

### alias 快捷指令

```
alias          # 查看已经设置了哪些快捷指令
alias  l       # 查看是否设置了 l 这个快捷指令
```

## 3. 特殊符号 {#symbols}

**1）重定向符号 `>`**：把输出写入指定的文件。

```
history  >  1.t                    # 把历史命令写进 1.t
echo 123 > 2.t                     # 把 123 写进 2.t
cat  -n  .bash_history  >  1.t     # 带行号写进 1.t
```

**2）管道符 `|`**：连接两个命令，把**前一个命令的输出**作为**后一个命令的输入**。

```
cmd1  |  cmd2
ll | grep '.txt'      # 列出内容后过滤出含 .txt 的行
```

## 4. Linux 的快捷键 {#hotkeys}

| 快捷键 | 作用 |
|---|---|
| `ctrl + L` | 清屏（clear 也可以） |
| 方向键 ⬆️⬇️ | 翻之前/之后的命令 |
| `ctrl + a` | 光标移动到**开头** |
| `ctrl + e` | 光标移动到**结尾** |
| 命令前加 `#` | 不想执行某个命令时，ctrl+a 回到开头加个 # 就变成注释 |

**打开文件后**：

| 按键 | 作用 |
|---|---|
| `G` | 跳转到文件**最后一行** |
| `gg` | 跳转到文件**第一行** |
| `g + f` | 直接在文件内跳转另一个文件 |
| `ctrl + o` | 返回原文件 |
| `!100` | history 之后，直接执行第 100 行执行过的命令 |

**tips**：帮助学习 cmd 的使用——`cmd --help`，展示命令的语法格式以及用法。
