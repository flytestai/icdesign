ICC2：换一套工具，把同一件事再做一遍

ICC2 Fundamentals

ICC2 的设计数据库（NDM）和 Innovus 完全不同，库要先"建"出来。这一课讲 NDM 是什么、怎么建、和 Innovus 的命令怎么对应。

约 35 分钟 课表学时 2 ICC2NDM建库
01

为什么换工具会卡住

会用 Innovus 不等于会用 ICC2。差的不只是命令名，而是数据组织方式：

维度InnovusICC2
库格式直接读 .lef + .lib必须先合成 NDM
设计存盘.enc 目录block 数据库（在 lib 里）
时序视图读 .lib 即可NDM 里必须有 timing view
命令风格place_opt_designplace_opt
NDMMilkyway/NDM 库点击看解释

Synopsys 的库格式。一个 NDM 里可以同时装：物理视图（来自 LEF）、时序视图（来自 .db）、工艺信息（来自 .tf）。
关键：如果 NDM 里只有物理视图没有时序视图，place_opt 会直接失败（报 OPT-041），因为它没法算时序。

02

建库：ICC2 的第一道关

造 NDM 要用 icc2_lm_shell（Library Manager），不是 icc2_shell。这是一条容易踩空的坑：两个 shell 的命令集是互补的。

tcl
# 在 icc2_lm_shell 里执行create_workspace -technology /pdk/tsmc32.tf tsmc32_ts read_lef /pdk/lef/tsmc32_stdcell.lef        # 先读物理read_db  /pdk/db/tsmc32_tt.db               # 再读时序 check_workspace                              # 检查一致性commit_workspace -output /pdk/ndm/tsmc32_ts.ndm   # 提交成 NDM
常见坑 · 建库时 check_workspace 不过，commit 会失败

常见原因：LEF 和 .db 里的单元对不上（比如某个单元只在 .db 里有，LEF 里没有）。

处理办法：把冲突单元从库里剔掉（remove_lib_cell），或者补一份匹配的 LEF。我们实测时踢掉了 3 个单元（LOGIC0/LOGIC1/TAPCELL），因为它们引脚名或物理信息不一致，剔掉不影响综合（DC 会改用反相器做 tie）。

04

一个真实的坑：OPT-041

我们第一次跑 place_opt 时报错：

shell
Error: OPT-041 Scenario Manager creation failed

官方文档会说"时序场景创建失败"，于是你会去查 NDM 有没有 timing view。但我们查了，有。

真正的原因在上一行日志：

shell
NEX-018: no valid parasitic for default corner (LATE)

缺的是寄生参数模型（TLU+），不是时序视图。

tcl
read_parasitic_tech -tlup /pdk/tlup/tsmc32.tlup -layermap /pdk/tlup/layer.map -name ttset_parasitic_parameters -early_spec tt -late_spec tt# 必须在 link_design 之后设置
工作场景 · 这个坑的教学价值

报错信息经常"指错方向"。OPT-041 看起来是场景问题，实际是寄生问题。

排查原则：不要只看最后一条错误，往上翻 5 行看第一条。 后面往往是连锁反应。

过关标准（都能做到才算学完）
  • 知道 NDM 里必须同时有物理视图和时序视图
  • 记得建库用 icc2_lm_shell 而不是 icc2_shell
  • 能说出至少 8 组 Innovus/ICC2 命令对应
  • 遇到 OPT-041 先查寄生参数
自测：先自己想，再点开答案
NDM 里缺时序视图会怎样？
place_opt / clock_opt 起不来（优化器需要时序信息）。
建库为什么要在 icc2_lm_shell 里做？
因为 read_lef/read_db/create_workspace 这些库管理命令只在 lm_shell 里有（icc2_shell 有 create_lib 但没有 lef/db 读取）。
OPT-041 的真实原因可能是什么？
常见是缺寄生参数模型（NEX-018），不是时序视图缺失。
Innovus 的 .enc 和 ICC2 的 block 数据库有什么区别？
.enc 是独立目录存盘；ICC2 的 block 存在 lib 里，要先 open_lib 再 open_block。
