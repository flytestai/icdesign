低功耗与 UPF：让芯片省电的四种手段

Low Power & UPF

功耗分动态和静态，降功耗有四种主流手段。UPF 用一份文件把"哪里能断电、断电时怎么隔离"讲给工具听。

约 45 分钟 课表学时 4 低功耗UPFclock gatingpower gating
01

功耗从哪来

类型公式什么时候耗怎么降
动态功耗P = α·C·V²·f信号翻转时降电压、降频率、减少翻转
静态功耗（漏电）与工艺、Vt 有关一直耗，哪怕不动用高 Vt 单元、断电

α 是翻转率，C 是电容，V 是电压，f 是频率。注意电压是平方项——所以降压最有效。

Leakage漏电点击看解释

晶体管关断时仍有微小电流漏过。工艺越先进，漏电占比越高（28nm 以下可能占 30%~50%）。
所以先进工艺里"静态功耗"是必须单独优化的一项。

02

四种手段

1. Clock Gating（时钟门控）

最常用、收益最大。模块不工作时，把它的时钟关掉。

shell
❌ 不加门控：时钟一直在翻转，即使数据不变也在耗电CLK ────────────────▶ [FF] [FF] [FF] ✅ 加门控：enable 为 0 时时钟停止CLK ──▶ [ICG] ──────▶ [FF] [FF] [FF]         ▲       enable
ICG集成时钟门控单元点击看解释

Integrated Clock Gating cell。一个带使能端的时钟门控单元。综合工具会自动插入（set_clock_gating_style），后端只需保证它被正确摆放和连接。
典型收益：时钟网络功耗降低 20%~40%。

2. Power Gating（电源关断）

整个模块断电，漏电直接归零。代价：断电后数据丢失，重新上电要复位。

需要三类特殊单元：

单元作用
Switch（开关）控制电源通断，通常用 PMOS 大管
Isolation（隔离）断电模块的输出不能悬空，要钳位到固定值
Retention（保持）需要保留状态的触发器，用特殊单元

3. Multi-Vt（多阈值）

关键路径用 LVT（快但漏电大），非关键路径用 HVT（慢但省电）。这个前面讲过，是最容易落地的省电手段。

4. DVFS（动态电压频率调节）

按负载调电压和频率。手机芯片常用：玩游戏时高频高压，待机时低频低压。

后端要支持多电压域（multi-voltage domain），复杂度最高。

03

UPF：把电源意图写成文件

工具不知道"这块能断电"，你得告诉它。UPF（Unified Power Format）就是这份说明书。

tcl
# 定义一个电源域：u_core 可以在关机时断电create_power_domain PD_CORE -elements {u_core} # 定义电源网络create_supply_net VDD      -domain PD_COREcreate_supply_net VDD_GATED -domain PD_COREcreate_supply_port VDD     -domain PD_CORE -direction in # 电源开关：用 header switch 控制 VDD → VDD_GATEDcreate_power_switch SW_CORE \    -domain PD_CORE \    -input_supply_port  {VDD VDD} \    -output_supply_port {VOUT VDD_GATED} \    -control_port       {SLEEP sleep_ctrl} \    -on_state           {on_state VDD {!SLEEP}} # 隔离策略：断电时把输出钳到 0set_isolation ISO_CORE \    -domain PD_CORE \    -isolation_power_net VDD \    -clamp_value 0
UPF统一电源格式点击看解释

一种用 Tcl 语法描述"电源域、开关、隔离、保持"的标准文件（IEEE 1801）。
综合、布局布线、验证工具都读它，保证大家对"电源怎么接"理解一致。

常见坑 · 忘了加 isolation，仿真过、硅片上挂

断电域的输出如果直接连到常开域，断电时会输出不确定电平（悬空），常开域可能收到错误值甚至短路电流。

UPF 里写了 set_isolation 只是"声明"，还要在实现时真正插入 isolation 单元：

tcl
# 综合阶段insert_isolation# 或后端阶段检查check_mv_design -isolation

"声明了但没插单元"是低功耗设计最常见的低级错误。

工作场景 · 低功耗项目的 review 问题
  1. "哪些域能断电？断电时输出怎么处理？"（UPF 里的 isolation 策略）
  2. "clock gating 覆盖率多少？"（一般要求 >90% 的触发器有时钟门控）
  3. "LVT 占比多少？"（>30% 要担心漏电）
  4. "多电压域之间的信号有没有电平转换器？"（level shifter）

四个问题答不上来，说明你只是跑了流程，没理解功耗设计。

  • 知道四种降功耗手段及各自代价
  • 理解 ICG / isolation / retention / level shifter 四个单元的作用

  • 能回答低功耗 review 的四个问题
自测：先自己想，再点开答案
动态功耗公式里为什么降电压最有效？
电压是平方项（V²），降 10% 电压，动态功耗降约 19%。
Clock gating 的原理和收益？
用 ICG 在模块不工作时停掉时钟，减少翻转；时钟网络功耗通常降 20%~40%。
Power gating 需要哪三类特殊单元？
电源开关（switch）、隔离单元（isolation）、保持单元（retention）。
UPF 里写了 isolation 就够了吗？
不够，还要在实现时真正插入 isolation 单元，并用 check_mv_design 验证。
Multi-Vt 优化的取舍是什么？
LVT 快但漏电大，HVT 慢但省电；只在关键路径用 LVT，占比一般控制在 10%~20%。
