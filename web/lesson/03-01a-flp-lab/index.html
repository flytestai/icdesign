Floorplan 实操：看懂芯片切角与端口清单

Floorplan Lab

第一讲对应知识库第 01 项主题，用上传 Word 的实操原文和原图理解 Die、Core、切角，以及全部端口与未摆放端口的区别。

预计学习 ≈6 分钟 课表学时 0 InnovusFloorplan实操Tcl
01

先认地图：Die、Core 和切角

资料来源

本讲按钉钉目录第 01 项《flp实操》的主题编排。下面的原文命令和截图来自你上传的《04 innovus项目(1).docx》Floorplan 实操部分，不是钉钉原文或原图的转载。为保留上下文，原站 Floorplan 完整课 仍保留原来的实操小节，首次学习任选一个入口即可。

把芯片平面想成一张地图：Die 是整块芯片的外轮廓，Core 是主要摆放电路单元的内部区域。做异形轮廓时，先定义初始边界，再在指定坐标范围切掉一块。先认清这两个动作，再去读参数；不要一上来就记项目里的坐标。

1.定义形状

floorplan -noSnapToGrid -b 0 0 935.712 456.456 0 0 935.712 456.456

1.2 1.2285 934.512 455.2275 #die 坐标 IO 坐标 core 坐标

addObjFPlanCutBox cell bpu40_vae_top_wrapper 0 0 566.352 228.228

#切角坐标。

原课件把 floorplan 的参数分成两行展示：从 floorplan -noSnapToGrid 到下一行的 Core 坐标，属于同一条命令。示例中的设计名、坐标都与该项目绑定；不要复制到其他项目直接运行。实际操作应先存一份测试数据库，执行后在 GUI 比对切角前后的外轮廓和 Core，确认切掉的是预期区域。

02

再查门牌：导出全部端口与未摆放端口

顶层端口是该模块和外部信号相连的接口。全部端口回答「设计有哪些接口」，未摆放端口回答「还有哪些接口没有在版图上分配位置」。后者应该是前者的子集，不是另一份不相关的名单。

2.抓取port

--抓取所有 port

set all_ports [dbget top.terms.name]

set fh [open "ports_from_db.txt" w]

puts $fh [join $all_ports "\n"]

close $fh

--抓取 unplace 的 port

set unplaced [dbget [dbget -p top.terms.pStatus unplaced].name]

set f [open "unplaced_terms.txt" w]

foreach t $unplaced { puts $f $t }

close $f

第一段直接取顶层端口名，再写入 ports_from_db.txt。第二段先挑出状态是 unplaced 的端口，再取名字，写入 unplaced_terms.txt。这两段查询不改端口摆放状态；open ... w 会覆盖同名文件，练习时请在自己的输出目录操作。

没有 Innovus 也可以完成本节的检查练习：假设全部端口是 clk rst_n data_in data_out，只有 data_in 和 data_out 尚未摆放，那么第一份清单有 4 行，第二份清单有 2 行。若第二份清单出现了完全不在第一份里的端口，应先核对两份报告是否来自同一个设计和运行版本。

03

跟做：比较两次端口快照

用下面两份虚构报告练习交付检查。两次放置都使用教学顶层 lab_top 和同一份网表；只调整 data_in 的放置状态，不改接口定义。

text
Snapshot     Total ports    Unplaced ports      NotesFP_BEFORE    4              data_in data_out    baselineFP_AFTER     4              data_out            placed data_in only
  1. 先比较总端口数，再逐一比对名字；相同的条数不能证明名字完全一致。接着计算未摆放集合的差：本例只少了 data_in，符合本轮目标。
  2. 在 GUI 定位 data_in，检查所在边、金属层、轨道和项目允许的引脚间距。状态不再是 unplaced 并不代表引脚一定放对了；如果落在禁止区域，仍不能认可这一版。
  3. 只在练习副本修改。保存 FP_BEFORE，记录本轮唯一变动，输出 FP_AFTER 并复查。出现意外新增端口、其他 Port 状态被改动或重复间距违例，就恢复 FP_BEFORE，不要在未知状态上继续改。
04

自检：你是在读数据库，还是在改版图？

  • 能在原图上区分芯片外轮廓和切角，并说明切角并不是摆放引脚。
  • 能说清两份清单各回答什么问题，并检查未摆放清单是否属于全部清单。
  • 能区分读取端口、修改端口状态和实际摆放这三件事。本课先完成读取与检查；按金属层、边和轨道摆放端口的原文示例，可接着看 Floorplan 完整实操。
05

独立深练：顶层镜像后，缺口应落在哪边？

模拟交接报告（单位：µm，非工具实测）。 模块局部外包框从 (0,0) 到 (400,200)，左下切去矩形 (0,0)–(40,60)。顶层给出的包框左下角是 (1000,500)，实例沿局部竖直中线 x=200 镜像后再平移。端口 req、ack 的局部点分别为 (0,90)、(400,130)，顶层接口按信号名对接。

text
模拟顶层导出     缺口左下—右上              req          ack          未摆A               (1000,500)—(1040,560)     (1000,590)   (1400,630)   0B               (1360,500)—(1400,560)     (1400,590)   (1000,630)   0

先独立交付。 写出任一点从局部到顶层的换算式，并把缺口两个角点、两根端口的坐标逐一算出。选一份可交接的导出；说明另一份为何看起来外框正确、端口也全部已摆，却仍不能对接。不要交换两个端口的名字来迎合顶层的位置。

标准判断。 X=1000+400−x，Y=500+y，因此 B 正确。镜像会交换原来两角的横坐标次序，计算矩形边界时要重新取最小值和最大值；纵坐标只平移，缺口仍在下边。A 只做了平移，外包矩形与 B 相同，但实际轮廓和两端口所在边都错了。单看包框或未摆计数都发现不了这类错误。

验收与回退。 从未改动的局部快照重新导出，再用顶层实际轮廓对比缺口边界、按名称核对全部接口，并确认端口仍在允许的边和轨道上。若导出与拼装结果不符，撤回本次坐标转换产物，恢复原导出配置，保留差异；不要移动局部端口来抵消顶层变换错误。
