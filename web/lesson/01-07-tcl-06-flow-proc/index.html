01

if 条件判断与四大铁律

本章目标会写 if/elseif/else 并背下四大铁律；会用 gets stdin 读输入、rand() 造随机数；三种循环知道什么时候用哪个；会定义 proc（带参/默认参数/args）并用 global 拿全局变量；能把全部知识串成一个综合脚本。

根据条件执行不同代码块，条件表达式需用 {} 包裹。比较运算符：== 等于、!= 不等于、>、<、<=、>=；逻辑：与 &&、或 ||（都写在 expr 里）。

语法骨架：

tcl
if {条件1} {代码块1} elseif {条件2} {代码块2} else {代码块3}

完整示例（成绩等级）：

Tcl 练习台在输入行敲 Tcl 命令，回车运行；输入 help 看支持的命令
set score 85
if {$score >= 90} {
    puts "成绩等级：A（优秀）"
} elseif {$score >= 80} {
    puts "成绩等级：B（良好）"
} elseif {$score >= 60} {
    puts "成绩等级：C（及格）"
} else {
    puts "成绩等级：D（不及格）"
}

常见坑 · 四大语法铁律（初学者最常踩坑，全部来自文档）
  1. } 和 elseif / else 必须同一行，中间必须有空格。
  2. if 后面的条件必须包在 {} 里，而且 { 必须紧跟条件，不能换行。
  3. 所有大括号、运算符必须是英文半角符号，禁止中文括号/空格。
  4. TCL 是严格"一行一条命令"：if 是单条完整命令，不能用换行把 } 和 elseif 切开。

为什么？因为 {...} 是"分组"——} 换行会让 TCL 以为命令提前结束了。

03

while 循环：三要素与死循环

适合不知道要跑几次、或有明确终止条件的场景（这正是 while 相对 for 突出的地方），循环时用条件加 break 结束。

while 就三个要素：初始化 → 判断 → 更新，缺了"更新"就是死循环。
Tcl 练习台在输入行敲 Tcl 命令，回车运行；输入 help 看支持的命令
set i 0                 ;# 1. 初始化
while {$i < 5} {        ;# 2. 条件（花括号必须跟在这一行末尾）
    puts "i = $i"
    incr i              ;# 3. 更新——忘了这行就是死循环
}
tclsh>%

示例：列表倒序复制

Tcl 练习台在输入行敲 Tcl 命令，回车运行；输入 help 看支持的命令
set source_list {100 200 300 400 500}   ;# 原列表
set target_list ""                      ;# 目标列表（存储倒序结果）
set i [expr {[llength $source_list] - 1}]  ;# 初始索引=列表长度-1（最后一个元素）
while {$i >= 0} {
    lappend target_list [lindex $source_list $i]  ;# 取当前索引元素追加到目标列表
    incr i -1              ;# 索引递减1（向前遍历）
}
puts "原列表：$source_list"
puts "倒序列表：$target_list"

无限循环写法：while {1}——一直循环（配合 break 退出）。练习台里跑了死循环也别怕，解释器有 20 万次保护会自动停。

04

foreach 与 for：另外两种循环

foreach：遍历列表元素（首选）——直接遍历列表中的每个元素，无需手动控制索引，语法简洁，类似 C 和 Python 中 for 循环的 for-in 写法。语法：foreach 变量名 列表 { 代码块 }。

EDA 真实场景：批量处理内存单元（这就是后端工程师每天写的 TCL）：

tcl
;# 定义内存单元列表set mem_list {    I_CONTEXT_MEM/I_CONTEXT_RAM_0_4    I_CONTEXT_MEM/I_CONTEXT_RAM_0_3    I_CONTEXT_MEM/I_CONTEXT_RAM_0_2    I_CONTEXT_MEM/I_CONTEXT_RAM_0_1}foreach mem $mem_list {    puts "正在处理：$mem"    change_selection [get_cells $mem]   ;# 选中当前内存单元    move_objects -delta {-50 0}         ;# 向左移动50个单位}

get_cells、change_selection、move_objects 都是工具提供的命令，TCL 负责把流程串起来。下面用 puts 模拟跑一遍：

Tcl 练习台在输入行敲 Tcl 命令，回车运行；输入 help 看支持的命令
set mem_list {
    I_CONTEXT_MEM/I_CONTEXT_RAM_0_4
    I_CONTEXT_MEM/I_CONTEXT_RAM_0_3
    I_CONTEXT_MEM/I_CONTEXT_RAM_0_2
    I_CONTEXT_MEM/I_CONTEXT_RAM_0_1
}
foreach mem $mem_list {
    puts "正在处理：$mem"
    puts "  change_selection [get_cells $mem]"
    puts "  move_objects -delta {-50 0}"
}

动手文档原题：偶数减奇数

用 for 循环计算 1-100 所有偶数减奇数的值。提示：expr {$i % 2} 判断奇偶（% 是取余），偶数加、奇数减。答案在 50 左右，跑出来对着看。

Tcl 练习台在输入行敲 Tcl 命令，回车运行；输入 help 看支持的命令
;# 参考实现（先自己写，写完再跑这个对照）
set result 0
for {set i 1} {$i <= 100} {incr i} {
    if {[expr {$i % 2}] == 0} {
        set result [expr {$result + $i}]   ;# 偶数加
    } else {
        set result [expr {$result - $i}]   ;# 奇数减
    }
}
puts "1-100偶数减奇数的值：$result"

proc：定义函数

核心语法：

tcl
proc 函数名 {参数1 参数2 ...} {    ;# 函数体    return 返回值}

关键点：proc = 定义函数；{} 包裹参数列表；return 返回值（不写 return 则返回最后一条命令的结果）；调用：函数名 参数1 参数2；获取返回值：[函数名 参数]。

无参函数：

Tcl 练习台在输入行敲 Tcl 命令，回车运行；输入 help 看支持的命令
proc sayHello {} {
    puts "Hello, Tcl!"
}
sayHello    ;# 使用（调用）函数，调用时无 {}
tclsh>%
这是浏览器内置的 Tcl 解释器（覆盖本课全部命令）：set / puts / expr / incr / append / 数组 / 列表 / if·while·foreach·for / proc 都能真跑。多行输入：先写上半句回车，解释器会等续行。

带参数的函数（最常用）：return 退出当前 proc，并把指定值作为这个 proc 的返回结果。

Tcl 练习台在输入行敲 Tcl 命令，回车运行；输入 help 看支持的命令
proc add {a b} {
    set sum [expr {$a + $b}]
    return $sum
}
set result [add 10 20]
puts "10 + 20 = $result"    ;# 用 [] 接收返回值

带默认参数的函数——默认参数写成 {参数名 默认值} 放在参数列表里：

可变参数函数（任意个数参数）——特殊参数名 args 接收剩余所有参数（以列表方式打包）。调用 sumAll 1 2 3 4 5 → args = {1 2 3 4 5}。

综合实战：串起全部知识点

把变量、列表、循环、函数、命令替换全部用上——EDA 风格的批量处理脚本：

Tcl 练习台在输入行敲 Tcl 命令，回车运行；输入 help 看支持的命令
;# 1. 定义数据（列表）
set mem_list {
    I_CONTEXT_MEM/I_CONTEXT_RAM_0_4
    I_CONTEXT_MEM/I_CONTEXT_RAM_0_3
    I_CONTEXT_MEM/I_CONTEXT_RAM_0_2
    I_CONTEXT_MEM/I_CONTEXT_RAM_0_1
}

;# 2. 定义函数（proc + 参数 + return）
proc report {mem idx total} {
    puts "进度：$idx / $total —— 正在处理：$mem"
    return 0
}

;# 3. 循环处理（foreach + llength + 命令替换）
set total [llength $mem_list]
set idx 0
foreach mem $mem_list {
    incr idx
    report $mem $idx $total
    puts "  change_selection [get_cells $mem]"
    puts "  move_objects -delta {-50 0}"
}

;# 4. 结果统计
puts "全部 $total 个单元处理完毕"

自测：先自己想，再点开答案
if 的四大铁律是什么？
① } 和 elseif/else 同行且中间有空格；② 条件用 {} 包裹且 { 不换行；③ 全部英文半角符号；④ 一行一条完整命令。
while 三要素？缺了哪个会死循环？
初始化→判断→更新；缺了"更新"（如 incr i）就死循环，无限循环用 while {1} + break。
三种循环分别用在什么时候？
while 靠条件结束；foreach 遍历列表首选；for 已知次数按索引走。
proc 不写 return，返回什么？
最后一条命令的结果。
args 必须写在参数列表什么位置？
最后。只有 args 时可传任意个参数；args 把传入参数打包成列表。
函数内要用外面的变量怎么办？
先 global 声明（读和写都要声明），否则访问不到。
