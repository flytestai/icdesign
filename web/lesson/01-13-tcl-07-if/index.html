if-elseif-else 语法

本章目标会写 if/elseif/else 并背下四大铁律；会用 gets stdin 读输入；会用 rand() 造随机数；能做出成绩等级判断和猜数字游戏。

根据条件执行不同代码块，条件表达式需用 {} 包裹，支持比较运算符（== 等于、!= 不等于、> 大于、< 小于、<= 小于等于、>= 大于等于）；逻辑运算：与 &&、或 ||。

语法骨架：

02

四大语法铁律（文档强调，初学者最常踩坑）

  1. 铁律 1：} 和 elseif / else 必须同一行，中间必须有空格。
  2. 铁律 2：if 后面的条件必须包在 {} 里，而且 { 必须跟在条件后面，不能换行。
  3. 铁律 3：所有大括号、运算符，必须是英文半角符号，禁止中文括号 / 空格。
  4. 铁律 4：TCL 是严格一行一条命令：if 是单条完整命令，不能用换行把 } 和 elseif 切开。
为什么有这些规定？

因为 {...} 是"分组"——} 换行会让 TCL 以为命令提前结束了。（第 2 讲的分组原理在这里兑现。）

自测
if 的四大铁律？
① } 和 elseif/else 同行且中间有空格；② 条件用 {} 包裹且 { 不能换行；③ 全部英文半角符号；④ 一行一条完整命令，不能用换行切开 if。
gets stdin 相当于 Python 的什么？
input()，从标准输入读一行存进变量。
rand() 的取值范围？
0 到 1 之间、不等于 1。配 int() 用：expr {int(rand()*100)} 生成 0-99 整数。
条件表达式必须用什么包裹？
{}，且 { 必须紧跟条件不能换行。
