4. 可变参数函数（任意个数参数）

args 是 TCL 特殊参数：接收调用时传入的所有参数，打包成一个列表。调用 sumAll 1 2 3 4 5 → args = {1 2 3 4 5}；调用 sumAll 10 20 → args = {10 20}。

规则：args 必须写在参数列表最后；如果只有 args，代表可以传 0、1、任意多个参数。

proc 核心语法总结（文档原文）

tcl
proc 函数名 {参数1 参数2 ...} {    ;# 函数体    return 返回值}

关键点：

  • proc = 定义函数
  • {} 包裹参数列表
  • return 返回值（不写则返回最后一条命令结果）
  • 调用：函数名 参数1 参数2
  • 获取返回值：[函数名 参数]

总结：Tcl 用 proc 定义函数；支持无参、有参、默认参数、可变参数；返回值用 return；调用方式：函数名 参数 或 [函数名 参数] 接收返回值。

自测
proc 不写 return，返回什么？
最后一条命令的结果。
默认参数怎么写？
proc f {a {b 5}} { ... }——{参数名 默认值}。
args 必须写在参数列表什么位置？
最后。只有 args 时可传 0、1、任意多个参数，args 把传入参数打包成列表。
函数内要用外面的变量怎么办？
先 global x 声明（读和写都要），否则访问不到。
怎么接收函数返回值？
[函数名 参数]——命令替换接住返回值。
