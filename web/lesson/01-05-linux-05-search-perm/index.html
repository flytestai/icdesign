01

1. grep：搜索关键字

语法：grep 关键字 文件。

命令作用
grep 关键字 文件搜索关键字所在的行
grep -n 关键字 文件名搜索关键字并且显示行号
grep -10n 关键字 文件名搜索关键字，前后各显示 10 行
grep -A10 关键字 文件名显示关键字后面 10 行（After）
grep -B10 关键字 文件名显示关键字前面 10 行（Before）
grep -R 关键字 目录/*递归搜索目录下所有文件（含子目录）

比如 /var/logs/ 下有 a1 a2 a3、D1/b1 D2/b2、D1/F1/c1 多层结构，grep -R error /var/logs/* 会一层层搜下去，把每个文件里带 error 的行都揪出来。

小技巧

搜索 log 里面的 error、搜索 rpt 里的内容，全靠 grep。配合下一节的 -A/-B 上下文选项，报错前后的线索一目了然。

2. 文件处理：移动 / 复制 / 搜索

本章目标grep 常用选项全部掌握；权限数字含义会算会改；tar 打包解压一条龙；正则表达式入门并能在 vi 里实战。

移动 / 重命名文件 mv：

text
mv  文件/目录   目录            # 移动mv  old_name    new_name       # 重命名

复制文件 cp：

text
cp  -option  文件/目录   保存地址
选项作用
-r / -R递归复制目录 + 里面所有文件子目录
-a递归复制、保留权限、时间戳、软链接等全部属性
-i覆盖文件前询问 y/n，防止误删
-f强制覆盖，不提示，直接覆盖已有文件
-n不覆盖已经存在的文件，直接跳过

常用组合：cp -rf（强制递归覆盖，不保留属性）；cp -rfa（强制递归覆盖，保留属性）。

搜索文件/目录 find：

text
find  路径  -type  f         # 搜索文件find  路径  -type  d         # 搜索目录find  路径  -name  名字      # 按名字搜索（如 -name k1）find  路径  -user  用户名    # 按文件的 owner 搜索find  路径  -maxdepth 6      # 限制搜索深度

link 软链接的创建：

text
cd  目的地的目录     # 例如 /proj/NLAln  -s  a  b        # 将 a 创建为 link，取名为 b

磁盘空间查看：du -sh ~/，查看自己家目录的空间占用情况。

3. 权限的修改

数字控制权限：r=4　w=2　x=1　-=0

text
chmod  757  目录/文件chmod  -R  757  目录      # 递归修改权限（如 a/b/c/d）

字母控制权限：

text
chmod  u+rwx   目录chmod  g+rw-x  目录chmod  o+r-wx  目录

修改所属用户：

text
chown  用户名  目录/文件名chown  -R  用户名  目录      # 递归修改

修改所属组：

text
chgrp  组名  目录chgrp  -R  组名  目录

创建用户组 / 添加用户到组 / 从组里删除：

text
groupadd  组名                  # 创建用户组gpasswd  -a  用户名  组名       # 添加用户到组里gpasswd  -d  用户名  组名       # 从组里删除用户

6. 去重排序 / 扩展正则

text
sort  -u  文件名          # 去重并排序grep  -E  正则  文件名     # 使用扩展正则表达式

特殊场景——在 vi 打开文件之后想搜索：

text
:%!              # 调用 linux 的命令:%! grep opt     # 过滤，只展示符合要求的内容；按字母 u 撤销:%! sort -u      # 排序去重

工作使用场景：搜索 log 里面的 error、搜索 rpt 里面的内容。

注意：grep 只能搜索普通文件中的内容；如果文件是压缩格式（如 Place.log.gz），不能使用 grep，要使用 zgrep。

3、搜索练习：

题目正则
搜索以 a 开头的行^a
过滤以 3 结尾的行3$
搜索以 t 开头以 k 结尾的行t.*k
搜索 tes 后面 2-3 个 a 再接 tktesa\{2,3\}tk
搜索纯数字的行[0-9]
搜索不包含字母的行[^a-z]
搜索空行^$
搜索 tes 中间 s 出现 3 次以上的行tes\{3,\}

正则表达式进行替换（vi 内）

text
:%s/old/new/g      # 全局替换:%s/old/new/gc     # 忽略大小写全部替换:%s/a/b/2          # 只替换匹配到的第二个关键字:g/正则表达式/d    # 按正则删除行

批量插入（文件内容如 a1a2a3a4，^$ 表示空行）：

text
:%s/^/要插入的值 /g    # 在每一行开头插入内容:%s/$/要插入的值 /g    # 在每一行结尾插入内容

grep 搭配正则表达式

text
grep  -E  "Startpoint|Endpoint|slack"    # 多关键字任一匹配grep  -E  "b$"                            # 以 b 结尾

应用场景（在 vi 内）：

text
:%! grep -E "Startpoint|Endpoint|slack":%! awk '{print $2}':%s/^/ecoAddReapetar /g:%s/$/ -cells BUFD4LVT/g

批量注释和取消注释（块处理文本）

加注释：ctrl+v 进入 block 块模式 → 上下方向键选择区域 → shift+i 回到开头行输入 # → 按 esc 批量应用所有行。

取消注释：ctrl+v → 方向键选择区域 → 直接按 d。

自测
grep 搜关键字并显示它前后各 10 行用哪个选项？
grep -10n 关键字 文件名；-A10 只显示后面 10 行，-B10 只显示前面 10 行。
r w x 的数字分别是什么？
r=4、w=2、x=1。757 = rwx r-x rwx。
cp -r 和 cp -a 的区别？
-r 只递归复制；-a 递归复制且保留权限、时间戳、软链接等全部属性。
tar 打包并压缩用什么参数？
-czvf（c 创建 z 压缩 v 显示过程 f 指定包名）；解压用 -xvf，解压到指定目录加 -C。
压缩过的 log 为什么 grep 搜不了？
grep 只能搜普通文件；压缩文件（如 Place.log.gz）要用 zgrep。
