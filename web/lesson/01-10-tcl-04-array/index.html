数组是什么、怎么定义

本章目标会用 set arr(key) 定义并访问数组；会用 array set 批量赋值并避开两个易错点；会用嵌套列表写法 + dict get 取嵌套字段；会用 unset 删元素/删数组并认识两种报错；会两种 foreach 遍历。

数组是"键 - 值对"的集合，键（索引）可以是字符串或数字，值可以是任意数据类型，适合存储关联数据（如学生姓名-学号、产品编号-价格）。它对应 Python 的 dict。

删除后再访问会报错（两种报错信息要认识）：

tcl
;# 承接上面的 student 数组unset student(002) ;# 删除学号002的元素puts $student(002) ;# 错误！can't read "student(002)": no such element in array unset student ;# 删除整个student数组puts $student(001) ;# 错误！can't read "student(001)": no such array
两种报错的区别

no such element in array = 数组还在、键没了；no such array = 整个数组没了。看到报错能立刻分清删的是键还是整个数组，调试就快一半。

自测
set 数组名(键) 值 什么时候是新增、什么时候是修改？
键已存在就是修改，不存在就是新增。
array set 的第一个参数有什么限制？
必须是不带括号和 key 的纯数组名，写 person(001) 会直接报错。
unset 数组(键) 和 unset 数组 的区别？
前者删单个元素（再访问报 no such element in array），后者删整个数组（再访问报 no such array）。
array names 和 array get 分别返回什么？
names 返回所有键名；get 返回键和值交替排列的扁平列表。
