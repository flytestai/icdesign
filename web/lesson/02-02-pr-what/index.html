什么是布局布线（PR）：把网表变成能送去生产的版图

What Is Place and Route

用一间毛坯房讲清 PR 到底在做什么：综合给的 netlist 只是逻辑连接，PR 把每个单元放到真实坐标上、用真实的金属线连起来，最后吐出 GDSII。顺带把 PD/DE/ME、block 与 top、三种线、芯片分类这些面试必问的名词一次说清。

预计学习 ≈16 分钟 课表学时 2 PR概念岗位blocktop芯片分类
01

先把一句话说死：PR 是什么

本章目标能用一句话说出 PR 的输入和输出（netlist → GDSII），能分清 PD/DE/ME 三个岗位，能说出 block 与 top 的区别、三种线分别是什么。

PR = Place and Route = 布局和布线。 它在做的事情只有一件：

把综合之后的 netlist（网表），变成可以送去工厂流片的 GDSII。

PR / PnR布局布线

Place and Route 的缩写，写作 PR 或 PnR 都行，指同一个流程：先把单元"摆"到芯片上的具体坐标（Place），再用金属线把该连的连起来（Route）。

netlist网表

综合工具吐出来的电路描述文件，后缀一般是 .v.gz（压缩的 Verilog）。它只说明"哪个引脚连哪个引脚"——逻辑连接，不含任何坐标、长度、层信息。

GDSII版图文件

送工厂加工用的版图文件（II 指的是二进制形式）。它描述每一层金属、每一个孔、每一个单元在硅片上的真实形状和坐标——物理连接。

用装修打个比方：综合给你的是"水电点位图"（哪个插座接哪根线，纸上画得清），PR 要把它变成"墙里真的埋进去的线管，位置精确到毫米"。图纸和施工图不是一回事，netlist 和 GDSII 也不是一回事。

常见坑 · 把 netlist 当版图

现象：面试被问"你交付的成果是什么"，答"综合出来的 netlist"。 原因：netlist 是逻辑网表，没有面积、没有坐标、没有金属层，工厂拿它没法生产。 正确说法：PR 的交付物是 GDSII（以及配套的 def、报告、时序数据库），netlist 只是 PR 的输入。

02

综合给的是逻辑连接，PR 才给出物理连接

完整链条上有三个关键节点，别混：

阶段谁做产物关键特征
综合（RTL → 电路）前端netlist（.v.gz）器件按功能连起来，只有逻辑关系
布局布线（PR）后端GDSII + def + 报告器件有坐标，线有层与宽度，物理可实现
签核（STA / PV / PA）后端/签核组通过的数据库证明它在各种 corner 下都能工作

举个具体例子理解"逻辑 → 物理"：

写一行 RTL always @(negedge rst) cnt <= 0;，意思是"rst 下降沿把 8 位寄存器 cnt 清零"。综合工具会把它翻译成一堆真实的门：反相器、与门、或门、多路选择器、触发器——逻辑上等价。但这时候还没有任何东西告诉工具：这个触发器放在芯片的哪个角落？它到下一个触发器的线要走第几层金属、绕多远？

这些正是 PR 要回答的问题。器件放得远、线绕得长，延迟就大，时序就过不去；放得挤，布线绕不开，DRC 就爆。所以 PR 不是"画图"，是在面积、时序、可制造性三者之间不停做交易。

03

三个岗位缩写：PD / DE / ME

看招聘 JD 时最先撞上的三个词：

PD物理设计工程师

Physical Design Engineer，也就是"后端"。负责把 netlist 做到 GDSII：floorplan、place、cts、route，以及中间无数轮优化。PR 就是 PD 的主战场。

DE设计工程师（前端）

Design Engineer。写 RTL、做综合、给后端交网表的人。后端发现"这条路径逻辑太深，怎么摆都过不了"时，要找 DE 改 RTL。

ME中端工程师

Middle End Engineer。夹在前后端之间：DFT（扫描链插入）、formal、低功耗结构、网表质量检查，也常负责 MMMC 环境与 sdc 的整合。不是所有公司都设这个岗，但大厂很常见。

一句话记法：DE 写逻辑，ME 加结构，PD 落到硅片上。

04

后端的两个方向：物理设计与时序设计

后端不只 PR 一件事，粗分两条线：

方向干什么常见工具
物理设计（Physical Design）布局、布线、时钟树、供电、DRC/LVS 收敛Innovus、ICC2
时序设计（Timing / STA）判断信号能不能"按时到达"，出时序报告、定约束PrimeTime、Tempus

两者不是上下级，是互相拉扯：PR 把线绕短一点，时序就好一点；时序要求太狠，PR 就得更费力地摆和绕，面积和功耗跟着涨。真实项目里这两个角色每天都要对账——所以本站后面既讲 Innovus，也单独讲 STA。

05

block 级和 top 级：你接到的活是哪一种

后端设计按层级分两类，决定了你每天要操心的东西完全不同：

block / tile模块（块级设计）

一个完整芯片被切成若干块，分给不同的人做。block 和 tile 是一个意思，就是"分给你的那块活"。块级设计的边界是别人定好的：面积多大、从哪进哪出（port 位置），你只管把块内部做干净。

top顶层（顶层设计）

把各个 block 拼成一颗完整芯片的那一层。要定整颗芯片的面积、每个 block 摆在哪、block 之间的连线怎么走，还要把电源网络从 pad 一路送到每个 block 里。

block 级top 级
边界别人给（面积 + port 位置）自己定
主要矛盾块内时序、拥塞、DRC块间连线、电源网络、全局拥塞
交付干净的 block（def/lef/GDS）整颗芯片 GDSII
交接方式top 用 def 把面积和 port 位置发给 block owner收回各 block 的 def/GDS 拼装

这张表里"top 用 def 把面积和 port 位置发给 block owner"是后面第 4 课的重点：def 是块级与顶层之间的合同，写错一个 port 坐标，块里所有接口逻辑都得重做。

06

布局：什么必须人摆，什么能自动摆

"布局"听着像全部自动，其实分三类器件，待遇完全不同：

macro / mem / sram宏单元、存储器

第三方厂商做好的成品 IP（内存、SRAM、模拟模块、PLL 等），有固定形状和固定引脚位置。必须由人（或脚本按人的策略）摆放到确定位置——工具不会自动帮你摆，因为摆错会同时毁掉时序和布线通道。

stdcell标准单元

标准单元库里的基本逻辑门（与、或、非、触发器等），等高、宽度不同、按行（row）排列。因为有统一的 lib/lef 描述，工具可以自动摆放、自动优化。

physical cell物理单元

只有物理信息、没有逻辑功能的单元：tap cell（阱接触）、endcap（行端帽）、decap（去耦电容）、filler（填充）。它们不进网表，是 PR 阶段按规则补进去的。

为什么 mem 要人摆？三个原因，面试常问：

  1. 引脚位置固定：mem 的 pin 在哪一侧是工艺决定的，摆错方向，线要从远处绕过来，时序和拥塞一起爆。
  2. 面积大：一个 mem 可能顶几千个 stdcell 的位置，摆歪了整块的布线通道就断了。
  3. 有物理禁忌：mem 上方通常禁止走线（routing blockage）、周围要留 halo，靠工具自动摆很容易踩规则。

所以真实项目里 floorplan 阶段最花时间的就是"mem 怎么摆"，摆完才轮到工具自动放 stdcell。

07

布线：三种线，三种命

"布线"不是一种线，是三种，优先级和做法都不同：

线干什么为什么特殊
供电（power）把电源/地从 pad 送到每个单元要够宽、要成网（mesh/strap）、要算 IR drop 和电迁移
时钟（clock）把时钟送到每个触发器的 clock 端要求"同时到达"（低 skew），要单独做时钟树，普通布线器不许随便动
信号（signal）其余所有数据/控制线数量最多，是拥塞和 DRC 的主要来源

这三条线分别对应流程里的三步：powerplan（打供电）→ cts（绕时钟）→ route（绕信号）。下一课就把整个流程串起来。

一句话记住优先级

供电最硬（做不好芯片会烧/不工作），时钟第二（做不好时序全崩），信号最后（做不好就慢慢修）。

08

模块分级与芯片分类：面试的"广度题"

模块分级：一颗芯片按层级切成一级模块、二级模块、三级模块。越往上（一级）越大越接近顶层，越往下越像"一个具体功能块"。分给你的活通常落在二级或三级模块上——这也解释了为什么招聘会写"负责 XX 模块的 PR"。

芯片分类（知道各自算什么就行，面试常拿来探你的知识面）：

类型是什么典型厂商/场景
SOC片上系统，把 CPU、总线、外设、存储接口集成到一颗手机主芯片、车规芯片
CPU通用处理器，看核心数、主频Intel、AMD
GPU图形处理器，大量并行计算NVIDIA、AMD
NPU神经网络加速单元手机/服务器 AI 芯片
DSP数字信号处理，音频、图像、通信基带音频/基带芯片
DDR缓存/内存接口控制器内存条、SoC 的存储接口
USB / PCIE高速串行传输接口外设、板级互连
VCN视频/音频编解码处理多媒体芯片

这些名字不影响你摆一个 stdcell，但影响你判断"这个项目大概多难"：接口类（DDR/USB/PCIE）对时序和信号完整性极敏感，NPU/GPU 则是面积和功耗的大户。

SOC：先进工艺的主流形态

SOCSystem on Chip 片上系统

把 CPU、GPU、DDR、USB、PCIe 等多个"原本各是一颗芯片"的功能，集成到一颗大芯片上。现在先进工艺上做的绝大多数都是 SOC。

从 top（顶层）的视角看，SOC 里的每个子模块（CPU、DDR 控制器、USB PHY……）都是一个大号的 stdcell 或 macro：

  • 你做其中某个 block 时，只关心它的内部；
  • 顶层工程师关心的是模块之间怎么连、数据流怎么走、时序怎么对接（下一课会讲 top 与 block 的分工）。

所以"SOC 内部的数据流走向与连接方式"这句话，翻译成工作语言就是：谁给谁送数据、走哪条总线、跨不跨时钟域/电压域。

求职视角：哪类模块最值钱

文档在这一段说得很直接，值得抄下来：

  • DDR、USB、PCIe 这几类模块难度最大——它们涉及跨电压域、低功耗设计、高速接口时序；
  • 尤其 USB 相关的低功耗项目，工作内容丰富、挑战大；
  • 面试官常问"做过 PCIe 传输吗""做过 DDR 接口吗"；
  • 简历上要明确写出你做过芯片里的哪个具体模块，并对整颗芯片的种类与构成有大致了解。
小技巧

不要写"负责后端物理设计"，要写：

负责 XX 芯片 DDR 控制器 block 的 PR：面积 XX mm²、频率 XXX MHz、完成 floorplan/CTS/route 与时序收敛，DCLS/IR 达标。

模块名 + 规模 + 频率 + 你做的那几步——四个要素齐了，面试官才有得问。

09

这一课在项目里的位置

把这一课放回真实时间线：

  1. DE 交来 netlist（第 N 版），ME 补好 DFT 和 MMMC 环境；
  2. 你作为 PD 接手，先搞清楚这块活的边界（block 还是 top、面积多大、port 在哪）；
  3. 导入数据（netlist + lef + lib + sdc + MMMC）；
  4. 走完 init → floorplan → powerplan → place → cts → optcts → route → optroute → chipfinish；
  5. 交出 GDSII + def + 报告，交给签核组做 STA / PV / PA。

下一课就把第 4 步这九个阶段一个一个拆开讲，并且告诉你每个阶段"做完怎么看它做得好不好"。

动手用一张纸画出这条链

在一张纸上从左到右写五个框：RTL → netlist → PR → GDSII → 流片。然后在每个箭头下面写一行字：这一步的产物是什么、谁做、下一个环节拿它干什么。

验收标准：能不看资料说清 netlist 和 GDSII 的差别（一个有坐标一个没有）、能说出 block 与 top 各交付什么、能说出三种线分别对应流程里的哪一步。

自测
PR 的输入和输出分别是什么？
输入是综合后的 netlist（网表）；输出是 GDSII（版图），以及 def、报告、时序数据库等配套文件。
PD、DE、ME 分别指什么？
PD = Physical Design Engineer（后端/物理设计）；DE = Design Engineer（前端，写 RTL、做综合）；ME = Middle End Engineer（中端，DFT、formal、MMMC 等）。
block 和 tile 有什么区别？
没有区别，是同一个东西的两种叫法，指分给某个人的那块模块设计。
为什么 mem/SRAM 必须人摆，stdcell 可以自动摆？
mem 是第三方 IP，引脚位置固定、面积大、上方常禁止走线；stdcell 等高、按行排、有统一 lib/lef 描述，工具能自动摆放和优化。
physical cell 是什么？举两个例子。
只有物理信息、没有逻辑功能的单元，不进网表，PR 阶段按规则补入。例如 tap cell、endcap、decap、filler。
布线有哪三种线？分别对应流程里哪一步？
供电、时钟、信号。供电对应 powerplan，时钟对应 cts，信号对应 route。
SOC 是什么？从 top 视角看它的子模块算什么？
System on Chip 片上系统，把 CPU/GPU/DDR/USB/PCIe 等功能集成到一颗芯片；从 top 看，每个子模块就是一个大号的 stdcell 或 macro。
简历里写项目经历，至少要有哪几个要素？
模块名（如 DDR 控制器 block）+ 规模（面积/门数）+ 频率 + 你负责的工序（floorplan/CTS/route/时序收敛）。
过关标准（都能做到才算学完）
  • 能用一句话说出 PR 是"把 netlist 变成 GDSII"
  • 能区分逻辑连接（netlist）与物理连接（GDSII）
  • 能说出 block 与 top 的边界由谁定、各自交付什么
  • 能说出三种线及对应的流程阶段
  • 能举出至少三种芯片类型并说出各自的特点
  • 能说出 SOC 的含义，以及为什么 DDR/USB/PCIe 这类模块在求职时更值钱
