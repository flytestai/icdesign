阶段二导读：后端基本概念与 PR 理论

Stage 2 Guide: Backend Fundamentals and PR Theory

阶段二已从"占位"扩充为 13 讲正式内容（28 学时）。本页是这一阶段的地图：每讲讲什么、彼此怎么咬合、先学哪个后学哪个，以及学完你应该能回答哪些问题。

预计学习 ≈7 分钟 课表学时 0 导读阶段二PR学习路线
01

这一阶段解决什么问题

本章目标知道阶段二的 13 讲各讲什么、顺序为什么这么排；能判断自己卡在哪一讲；明确学完这一阶段应具备的能力边界——能读懂一份 PR 交接数据、能说清一份时序报告的前提条件、能听懂同事在说什么。

阶段一的 Linux 和 Tcl 是"手上的工具"，阶段二才进"后端的语言"。这一阶段不讲怎么点工具，只讲概念、文件和它们之间的关系——因为 PR 的绝大部分事故，根因都不在操作，而在"拿到的这份数据是什么、它意味着什么"。

课表上这一阶段标的是 4 学时，本站按实际需要扩到了 28 学时：概念类内容讲不透，后面 41 学时的 Innovus 实操就会全程"照抄步骤但不知道为什么"。

03

为什么是这个顺序

text
【基础篇】 [1] 电路基础 -> [2] 设计全流程 -> [3] 电学与单位                                  |                                  ↓【PR 篇】  [4] PR 是什么 -> [5] 九步流程 -> [6] 要哪些文件 -> [7] 版本与迭代                                                              |    [8] lef（形状） -> [9] pin/port（接口） -> [10] lib/rc tech（时间）                    -> [11] setup/hold + corner -> [12] MMMC（多环境） -> [13] sdc（要求）

三条理由：

  1. 基础篇不先过，后面全是天书。不知道什么是触发器、不知道 28nm 指什么、不知道 ns 和 ps 差 1000 倍，读 lib 和 sdc 就是背单词。
  2. 先有地图再挖细节。第 5 讲先把九道工序走一遍，第 6~13 讲再逐个拆文件——反过来先看 lef，你不知道它在整个流程里干什么用。
  3. 时序那条线必须连着走。第 10 讲（lib/rc tech，延迟怎么算）→ 第 11 讲（setup/hold 与 corner，怎么判合格）→ 第 12 讲（MMMC，在几个世界里判）→ 第 13 讲（sdc，要求从哪来）。中间断一节，后面的配置就变成抄参数。
04

学完应该能回答的问题

后面每一讲的 :::check 都是这套问题的细化。如果下面这些你都能顺畅答出来，这一阶段就可以过了：

过关标准（都能做到才算学完）
  • 晶体管三个极是什么？FinFET 解决了什么问题？28nm 指的是什么？
  • 芯片从需求到封装出货，中间有哪七段？每段的交付物是什么？
  • 1ns 等于多少 ps？lef 里的 0.06 指的是多少 nm？
  • PR 的输入和输出分别是什么文件？为什么说它是"逻辑连接变物理连接"？
  • 九步流程里，哪一步决定芯片面积？哪一步最容易出 DRC？
  • init 阶段少给了 mmmc 文件，会有什么现象？（提示：不报错，但时钟为 0）
  • tech lef 和 cell lef 各描述什么？lef 与 def 的区别是什么？
  • 一个 cell 的延迟由哪两个量决定？transition 的值从哪来？
  • tsc28_lvtssg0p81v125c.lib 这个文件名能读出哪些信息？
  • 为什么 setup 用慢 corner、hold 用快 corner？
  • set_input_delay 约束的到底是什么？只写 -max 不写 -min 会怎样？
学习建议

这一阶段的课不要只看不动手。每讲都带可以在浏览器里跑的练习终端（阶段一学的 Linux 命令全都能用），看到 lef、sdc 这类文件内容时，亲手 grep 一遍，记忆强度完全不一样。

配套资源：每讲底部有自测题，题库 可以随机抽题，术语表 能按阶段筛出这一阶段所有中英对照术语。

自测
阶段二现在一共有几讲、多少学时？分哪两篇？
13 讲、28 学时（课表原标 4 学时，按实际需要扩充）；分基础篇（晶体管/全流程/电学单位）与 PR 篇（PR 概念/流程/数据/文件/时序约束）。
为什么把"数据准备"放在 lef 和 lib 之前讲？
先建立"要哪些文件"的清单，再逐个深入内容；否则打开 lef 时不知道它在整个流程里干什么用。
可以先跳过基础篇直接读 PR 篇吗？
不建议、但可以"边读边补"。基础篇三讲是后面所有内容的词汇表与单位表；完全跳过会在 lib、sdc 上卡住。
可以跳过阶段二直接学 Innovus 实操吗？
不建议。实操每一步都在用这一阶段的概念（floorplan 算面积、cts 理解 skew、route 理解 DRC），概念不清就只能照抄步骤。
