Linux 3 - Files & Directories

ls / ll 全部常用选项与输出解析；cd / realpath / pwd / history；mkdir / rmdir / rm；touch 创建文件与通配符；课后练习一（19 题）。

01

1. 查看目录：ls

本章目标ls 全部常用选项信手拈来；看懂 ll 的 12 列输出；会建/删目录和文件；通配符用熟。

ls（list）：

  • 用法 1：ls 展示当前所在目录的内容；
  • 用法 2：ls 路径 展示指定路径下的内容。

2）常用 option

选项作用
ls -l展示目录下的详细信息（简写 ll）
-a展示所有的内容，包含隐藏文件
-h人类可读大小，字节换算成 K/M/G
-t按修改时间排序，新文件放前面
-r反转排序（从小到大 / 旧到新）
-S按文件大小排序，大的在前
-R递归列出目录下所有子目录内容

tree 目录：查看目录层级。

组合用法

  • 根据时间排序：ls -lt；
  • 根据时间、文件大小排序：ls -lrth（最常用），或 ll -rth。
小技巧

ll -rth：按时间从旧到新排列，最新的文件永远在最底下——查 log、找最新 run 必备。

3）解析 ll 查看详细内容

以 lrwxrwxrwx. 1 root root 7 Dec 18 2018 为例：

  • 第一列：内容的类型
  • - 普通的文本文件、log 文件、脚本文件、包
  • d 目录
  • l 链接 Link
  • 第二列到第十列：权限（下一节细讲，先记住结构）
  • r read　w write　x excute　- 无权限
  • rw- 所属用户权限；r-- 所属组的权限；r-- 其他人的权限
  • 第 11 列：所属用户的用户名
  • 第 12 列：所属组的组名
02

2. 切换目录：cd

写法作用
cd 路径进入指定目录
cd 或 cd ~回到当前用户的家目录
cd ..切换到上一级目录
cd .当前位置（原地不动）
cd -回到上一次打开的目录

相对路径 vs 绝对路径：

  • 相对路径：不以 / 开头的路径（从当前位置出发）；
  • 绝对路径：以 / 开头就是绝对路径（从根出发）。
03

3. 三个查位置的命令

realpath：获取某个文件的绝对路径。

text
realpath 文件名/root/A1/A4/abc

pwd：显示当前目录的绝对路径。

history：查看命令的历史记录。

04

4. 目录管理

mkdir 创建目录，语法：

text
mkdir  目录名字mkdir  目录1  目录2       # 创建多个目录mkdir  A1/{a,b}          # 同时在 A1 目录下创建 a 和 b 目录mkdir  -p  a/b/c/d/e     # -p 按照层级创建目录

rmdir 删除空目录：

text
rmdir  目录名rmdir  目录1  目录2      # 删除多个空目录

rm -rf 删除非空目录 / 强制删除 / 删除文件：

text
rm  -rf  目录名
常见坑 · rm -rf 是不可逆操作

删错目录没有回收站可找。敲 rm -rf 之前先停一秒确认路径，尤其是带通配符的时候。

05

5. 文件管理

text
touch  文件名            # 创建文件touch  文件1  文件2  文件3   # 创建多个文件rm    文件名             # 删除文件rm  -rf  文件名          # 强制删除

通配符

* 表示 0 个或任意多个字符：

通配符匹配
a1*以 a1 开头的文件或目录
*b以 b 结尾的文件或目录
*a*包含 a 的文件或目录
a*b以 a 开头 b 结尾的文件或目录
a*y*ba 开头、中间有 y、b 结尾

比如目录里有 a12nn3b、b123kkb、a234yyb：a*y*b 只匹配 a234yyb。

自测
ll -rth 是什么组合？
详细信息 + 反转 + 时间 + 人类可读大小：按修改时间从旧到新列出，最常用的组合。
mkdir -p a/b/c/d/e 的作用？
按层级一次性创建整条目录链（父目录不存在也能建）。
cd - 和 cd .. 的区别？
cd - 回到上一次打开的目录（来回切换），cd .. 是上一级目录。
通配符 a*y*b 能匹配 a234yyb 吗？
能：a 开头、中间含 y、b 结尾。a12nn3b 就不匹配（没有 y）。
