Linux 第 6 课 · 文本三剑客：sed / awk / gvim

Linux 6 - sed, awk & gvim

sed 打印/新增/删除/替换（含 -i 注意事项）；awk 完整语法框架、内置变量、常用函数与 10 条实操；gvim 常用命令全套（设置/光标移动/编辑/可视/分屏/.vimrc 配置）；课后 awk 练习。

约 60 分钟 课表学时 2 Linuxsedawkgvim文本处理
01

1. sed

本章目标sed 的打印/新增/删除/替换四种操作全部上手；awk 三段式框架和内置变量记牢，能独立完成列提取练习；会用 gvimdiff 对比文件。
常见坑 · 所有操作不加 -i 都不会修改原文件

sed 默认只把处理结果打印到屏幕，原文件不动；要真正写回文件需要加 -i。先用打印模式确认效果，再决定是否加 -i。

1、打印指定的行

text
sed -n '2p'   文件     # 打印第 2 行内容sed -n '3,5p' 文件     # 打印第 3 行到第 5 行内容

2、在指定行新增内容

text
sed '2a 内容' 文件     # 在第 2 行后面追加内容sed '3i 内容' 文件     # 在第 3 行前面插入内容

3、删除指定行内容

text
sed '3d'    文件      # 删除第 3 行sed '2,5d'  文件      # 删除第 2 行到第 5 行内容

4、替换指定的内容

text
sed 's/old/new/g'   文件   # 替换所有行的某些关键字sed '3s/old/new/g'  文件   # 只替换第 3 行的某些关键字sed '2c 内容'       文件   # 替换第 2 行整行sed '2,5c 内容'     文件   # 替换第 2 行到第 5 行
02

2. awk

awk 实操热身：

1、进入家目录；2、创建文件 test_awk.txt，写入以下内容：

text
aaaa bbbb cccc1111;2222;3333qqqq:wwww:eeee

热身问题：3、取出 cccc；4、取出 wwww；5、打印第 2 行整行内容；6、打印第三行的第 1 列和第 3 列；7、打印第 2 列大于 1200 且第三列小于 4000 的行。

核心语法结构

awk 三部分核心框架，可单独/组合使用：

text
awk 'BEGIN{初始化操作} 条件{处理动作} END{收尾操作}' 文件名
  • BEGIN：执行处理前运行（仅 1 次，比如定义变量）；
  • 中间块：逐行处理文件，满足条件才执行动作（最常用）；
  • END：所有行处理完后运行（仅 1 次，比如统计结果）。

必记内置变量

变量含义
NR当前处理的行号
NF当前行的字段总数（一行 3 列则 NF=3）
$NF直接取最后一列
$0当前整行内容
$n第 n 个字段（$1 第 1 列，$NF 最后 1 列）
FS字段分隔符（等价于 -F 参数）

常用操作符

  • 比较：> < >= <= == !=（字符串用双引号包起来，如 $1=="root"）
  • 逻辑：&&（且）　||（或）　!（非）
  • 匹配：/字符串/（包含该字符串），!/字符串/（不包含）

常用函数

gsub("旧","新")：全行替换指定内容。

text
awk  -F ':'  'NR==2{print, gsub(old, new)}'  文件

substr($1,1,3)：截取 $1 的第 1 个字符起共 3 位。

text
awk -F ':'  '{print substr($1, 1, 3)}'  文件

length()：取字符长度。

text
awk -F ':'  '{print length()}'           文件    # 打印每一行的长度awk -F ':'  '{print length($1), $2}'     文件    # 打印第一列、第二列的长度

实用实例

text
awk '{print $1}'  file.txt                    # 打印文件第 1 列awk '{print $1, $3}'  file.txt                # 打印第 1、3 列（空格分隔）awk '{print $2}'  file.txt | sort -u          # 打印第 2 列且去重awk '$3>100 {print $0}'  file.txt             # 按条件筛选（第 3 列 > 100 才打印）awk '$1=="root" && $2>50 {print $0}'  file.txt    # 多条件筛选awk 'END{print NR}'  file.txt                 # 统计文件行数awk '/test/ {count++} END{print count}'  file.txt # 统计符合条件的行数（第 4 列包含 test）awk -F ',' '{print $2}'  file.csv             # 自定义分隔符（逗号，取第 2 列）awk 'NR==2{print $3}'  file                   # 输出指定行指定列awk 'NR==3{print $0}'  file                   # 输出指定行

3. gvim 常用命令

gvim 和 vim 功能完全一致，多了 GUI 界面。下面几张表是日常后端工作真正高频的命令——每个都动手敲一遍，形成肌肉记忆。

3.1 常用设置（:set 系列）

text
:set nu      显示行号          :set nonu   取消行号:set wrap    分行显示          :set ic     搜索忽略大小写:set noic    搜索区分大小写:set paste   粘贴模式（防止从别处粘代码时自动缩进错乱，粘完 :set nopaste 恢复）:set noh     取消搜索高亮

3.2 光标移动

按键作用
h j k l左 下 上 右（手不离主键区的移动四键）
0 / $跳到行首 / 行尾
w / b下一个 / 上一个单词开头
gg / G文件第一行 / 最后一行
:10跳转到第 10 行（配合 :set nu 使用）

3.3 编辑操作（效率核心）

按键作用
yy / dd复制一行 / 剪切（删除）一行
3yy / 5dd复制 / 剪切 n 行（数字前缀）
p / P粘贴到光标下方 / 上方
u / ctrl+r撤销 / 重做
x删除光标处单个字符
dw / d$删除一个单词 / 删到行尾
ciw删除当前单词并直接进入插入模式（改一个变量名极快）
A / I在行尾 / 行首进入插入模式
r替换光标处单个字符
小技巧

把一行配置复制到另一个 run 目录的脚本里：光标停在该行按 yy，切到目标位置按 p——比鼠标复制粘贴快得多。

3.4 可视模式

按键作用
v字符可视模式（自由选区）
V行可视模式（整行选择，选中后 d 删 / y 复制）
ctrl+v块模式（第 5 课的批量注释用的就是它）

3.5 分屏

命令作用
:sp 文件上下分屏打开文件
:vsp 文件左右分屏打开文件
ctrl+w 再按 w在分屏之间循环切换
ctrl+w + 方向键按方向切换到指定分屏
:only关闭其它分屏，只保留当前

3.6 命令行补充

命令作用
:x保存并退出（等价 :wq，更快）
:w !sudo tee %打开时忘了加 sudo，仍能以管理员权限保存
:!命令在 vim 里临时执行 shell 命令（如 :!ls）

3.7 配置文件三兄弟（家目录下）

文件用途
.bashrcshell 启动配置（alias、环境变量）
.alias快捷指令
.vimrcvim/gvim 启动自动加载的配置

.vimrc 常用配置示例（写进去，每次打开 gvim 自动生效）：

text
set nu           " 显示行号syntax on        " 语法高亮set ts=4         " Tab 宽度 4 空格set expandtab    " Tab 转空格set autoindent   " 自动缩进set ic           " 搜索忽略大小写

比较两个文件的不同：

text
gvimdiff  file1  file2

文件内跳转练习：在家目录下创建 t1 和 t2：

  • t1 文件内容：this is t1 file，以及 t2 file path is ''（用 realpath t2 填入 t2 的绝对路径）；
  • t2 文件内容：this is t2 file。

用 g + f 从 t1 里跳到 t2，ctrl+o 返回原文件。

04

动手练：awk 练习

动手awk 练习（10 题）

1、回到家目录 2、创建文件 demo_awk.txt 3、在 demo_awk.txt 中输入以下内容： demo 111 222 333 clock 444 555 666 test:777:888:999 run;1;2;3 icc/4/5/6 4、取出第五行的 6 5、取出 222 6、取出 999 7、根据冒号分割，取出第 2 列大于 400 且第 4 列小于 1000 的行的第 2 列 8、根据空格分割，取出第 2 列大于 100 小于 200 的行的第 3 列 9、根据冒号分割，取出第 2 列等于 777 的第 3 列 10、根据空格分割，取出第 3 列不等于 222 的整行

自测
sed 怎么才真正修改文件？
加 -i 选项；不加 -i 只打印结果，原文件不变。
awk 里 $2 和 $NF 的区别？
$2 是第 2 列；$NF 是最后一列（NF 是该行总列数）。
awk 按 : 分割取第 3 列怎么写？
awk -F ':' '{print $3}' 文件。
统计文件行数的 awk 命令？
awk 'END{print NR}' 文件。
gvim 里复制一行再粘贴用什么？
yy 复制当前行，p 粘贴到光标下方；u 撤销、ctrl+r 重做。
:vsp 和 :sp 的区别？
:vsp 左右分屏打开文件，:sp 上下分屏；ctrl+w 再按 w 在分屏间切换。
