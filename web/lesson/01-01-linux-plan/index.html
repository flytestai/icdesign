Linux 基础命令和文本处理进阶（课表 12 学时）

Linux Fundamentals & Text Processing

阶段一第一门课：Linux 基础命令和文本处理进阶，课表 12 学时。先给出课程规划与模拟终端练习入口，正文内容建设中。

约 40 分钟 课表学时 12 LinuxShell文本处理
01

这门课讲什么

本章目标能独立在 Linux 终端里完成文件操作、文本处理与进程管理；为 TCL 课程和后续 EDA 工具课打好终端基本功。

按课表，本门课共 12 学时，规划如下（正文建设中，先在此占位）：

专题内容要点
终端与文件系统cd / ls / pwd / mkdir / cp / mv / rm，路径与权限
文本三板斧grep / sed / awk，报告行提取实战
查看与统计cat / less / head / tail / wc / sort / uniq
进程与作业ps / kill / top / 后台运行 / nohup
Shell 基础环境变量、.bashrc、alias、脚本入门
压缩与传输tar / gzip / scp / rsync
学完 Linux 直接进入 TCL

阶段一的下一门课是 TCL 基础和编程（课表 6 学时，本站 10 讲），已经上线——TCL 全部 10 讲都带浏览器内可运行的练习台，另配独立练习场。EDA 工具每天跑在 Linux 上，Linux 不熟，后面每一步都别扭。
