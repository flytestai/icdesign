ChipFinish：收尾这一步，决定能不能送厂

Chip Finishing & Tapeout Handoff

布完线、时序过了，版图还不是成品。ChipFinish 收四件事：填补（filler/tap/endcap）、铺平（metal fill）、包壳（seal ring 与 pad）、验证与交付（DRC/LVS 与文件包）。这一课逐项讲清为什么做、判据是什么，以及课程环境能做到哪一步。

约 28 分钟 课表学时 2 ChipFinishfillermetal filltapeout交付物
01

ChipFinish 到底在收什么

本章目标学完这一课，你能列出送厂前的十项检查并说出每项的判据，说清 filler 为什么必须从大到小、metal fill 为什么影响时序，并分清给工厂和给同事的交付物差在哪。

交房前有一道工序叫收尾：补墙缝、打磨地面、装门装锁、最后验房。这些活不改变户型，但不做就交不了房，或者交了也住不了。

芯片也一样。route_opt 之后，版图上到处是空隙：标准单元行里有空位、金属层有大片空白、芯片边缘没有任何保护。这些东西不影响时序，但会让工厂做不出来，或者做出来就是坏的。

收尾就四件事，按顺序做：

#收什么具体动作不做会怎样
1填补插 filler cell 填空隙；补 well tap 和 endcap阱/衬底不连续，LVS 报大量错误；工厂拒收
2铺平铺 metal fill（dummy），让每层金属密度达标CMP 后表面不平，后层光刻失焦，良率暴跌
3包壳加 seal ring（密封环）和 bond pad（焊盘）切割崩边、水汽进入；无法封装
4验证与交付签核级 DRC/LVS、出 GDS/OASIS、写交接说明工厂没法开工；接手的人要重新摸两周

顺序不能乱：filler 会改局部电容，metal fill 会加耦合电容，两者都要在最终时序复查之前做完；DRC/LVS 必须在所有几何改动之后跑，否则你验证的是旧版图。

ChipFinish芯片收尾点击看解释

布线优化完成之后、送厂（tapeout）之前的最后一组物理操作：填 filler、铺 metal fill、加 seal ring 与 pad、跑签核检查、打包交付物。
它不改逻辑、不改时序目标，只保证版图"造得出来、切得开、封得上、交得清"。

Tapeout流片/送厂点击看解释

把最终版图（GDSII 或 OASIS）交给工艺厂开始制造。这个词也常用来指"定版"这个动作——tapeout 之后再改，就要重做掩膜，费用以百万计。

工作场景 · 送厂前一周被退回

你交了 GDS，工厂回邮件：

text
Metal density violation on Metal3: 18% (min 30%)

意思是 Metal3 这一层只铺了 18% 的金属，低于工艺要求的最低密度 30%。原因很简单：你没铺 metal fill。

补救要重跑 metal fill → 重跑 DRC → 重新出 GDS → 重新走一遍交付流程，一周没了。而这条规则在工艺文档的第一页就写着——收尾的每一项都是"早就知道、就是忘了"的类型。

02

填 filler：顺序错了会把时序搞坏

标准单元宽度不一样（X1、X2、X4……），摆完必然留下宽度不一的空隙。空隙不填，会出三个问题：

  1. 阱和衬底不连续。 单元靠 well tie 连成一片，中间断开就没有衬底接触，LVS 会报错，电路也可能闩锁。
  2. CMP 不平。 有空隙的地方密度低，抛光时磨得更深，表面出现凹陷。
  3. 电源轨不连续。 标准单元行的 VDD/VSS 轨道要靠单元拼接才连通，空隙会把它切断。
tcl
# 作用：Innovus 里填 filler，从大到小给清单# 用法：时序基本收敛之后执行；单元名按你的库改addFiller -cell {FILL_X8 FILL_X4 FILL_X2 FILL_X1} -prefix FILLER   ;# 清单顺序就是优先级，大的在前checkFiller                                                        ;# 检查是否还有未填的空隙# ICC2 的等价命令：create_stdcell_fillers -lib_cells {FILL_X8 FILL_X4 FILL_X2 FILL_X1}

为什么必须从大到小，看一个具体例子就明白。假设行里有一段 5.0µm 的空隙，库里有 X4（4.0）、X2（2.0）、X1（1.0）：

text
从大到小（正确）：  [   X4   ][ X1 ]                  2 块，刚好 5.0，边界 1 条 从小到大（错误）：  [X1][X1][X1][X1][X1]              5 块，边界 4 条  单元数 ×2.5，每个边界都要过一遍 LVS，还多占面积和漏电 有障碍物时更糟：空隙 9.0µm，中间 4.2µm 处有一个不能挪的 decap  从大到小： 左段 4.2 放 X4，右段 4.8 放 X4 + 0.8（< X1，留缝）  从小到大： 左段被 X1 逐个切碎，右段剩 4.6 → X4 放得下 → 剩 0.6 < X1 → 留下 0.6µm 窄缝（notch）

那个 0.6µm 的窄缝就是灾难：填不进去，LVS 报"well 不连续"，CMP 在这一小块凹下去。先小后大等于把大空隙切碎，最后谁也填不满。

所以规矩是：清单从大到小，让工具优先用大块，小块只负责补最后那点缝。

除了 filler，还有两个容易漏的：

结构作用命令漏了会怎样
Well tap（井接触）给阱/衬底提供电位接触，防止闩锁addWellTap -cellInterval 40闩锁风险，ERC 报错
Endcap（端帽）标准单元行两端的收边单元，保证边界处的阱和注入层完整addEndCap行两端边缘 DRC 违例
常见坑 · 填完 filler 不重新检查时序

现象：filler 填完直接出 GDS，签核时发现 WNS 从 +0.05 变成 −0.03。 原因：filler 会改变局部电容；如果用了带 decap 的 filler（去耦电容单元），还会改变电源网络的充放电行为，间接影响延迟。 处理：填完 filler、铺完 metal fill，各跑一次 report_timing，和基线比。变了就查是不是新加的单元引起的。收尾阶段的每一次几何改动，都要有一次时序复查。

Filler Cell填充单元点击看解释

没有逻辑功能的标准单元，只用来占位。填在标准单元行的空隙里，保证阱、衬底、电源轨连续。
库里有 FILL_X1/X2/X4/X8 等不同宽度，工具按空隙宽度从大清单里挑。

03

metal fill：为了抛光平整

化学机械抛光（CMP）是把芯片表面磨平的一道工艺。它的工作原理像砂纸：软的地方磨得多，硬的地方磨得少。

如果某一层金属疏密不均（比如一块区域 80% 是金属、旁边只有 10%），磨完表面就是波浪形的。下一层光刻要在这种表面上曝光，焦距对不准，图形就糊了。

所以工艺厂给每层定了密度窗口，而且不是全芯片平均，是按窗口检查（典型 100×100µm 一个窗口）：

  • 每层密度要在 30%~70% 之间（典型值，看工艺文档）；
  • 每个窗口都要达标，不能靠别处多铺来平均；
  • 相邻层的密度也要接近，否则层间应力不均。

补密度的办法就是铺 metal fill（也叫 dummy metal）：在空白处插一堆不连接任何网络的金属块。

tcl
# 作用：Innovus 里先查密度，再铺 metal fill# 用法：filler 填完之后执行；层名按你的工艺改checkMetalDensity                                     ;# 先看哪一层、哪个窗口不达标addMetalFill -layer {M1 M2 M3 M4 M5} -timingAware true ;# 铺填充金属，避开关键网络checkMetalDensity                                     ;# 铺完复查，密度可能还不够，要迭代

-timingAware 是这里最关键的取舍：

做法优点缺点什么时候用
普通 dummy（不感知时序）快，密度容易达标可能贴在关键线旁边，加耦合电容，把 WNS 拖差 30~80ps时序余量充足（> 200ps）、非关键层
timing-aware dummy避开关键网络和时钟，时序安全跑得慢，密度可能不达标，要迭代几轮时序紧（< 100ps）、时钟网络附近

选错的代价很具体：一个时序只剩 30ps 余量的设计，被 dummy 加了 50ps 耦合，直接违例，而这时候你已经没有空间再改了——收尾阶段插不进 buffer。

常见坑 · 只查全芯片平均密度

现象：checkMetalDensity 报"平均 42%，达标"，送厂被退回，说某个窗口只有 12%。 原因：CMP 关心的是局部平整度，全芯片平均没有意义。工艺厂的检查是逐窗口的。 处理：看报告里的最差窗口，不是平均值。铺完 fill 一定要按窗口复查，并且检查相邻层的密度差。

Metal Fill金属填充（dummy）点击看解释

为了满足密度规则，在空白区域插入的不连接任何网络的金属图形。它不参与电路功能，只影响制造工艺的平整度。
代价是引入额外的寄生电容，所以关键路径附近要用 timing-aware 模式避开。

04

seal ring 与 pad：芯片的"外壳"

芯片从晶圆上切下来（die saw）的时候，刀片会产生微裂纹。裂纹如果延伸到电路区，芯片就废了；水汽也会从边缘渗进来，几年后腐蚀金属。

所以芯片四周要围一圈"墙"：

结构作用谁提供注意
Seal ring（密封环）环绕芯片的金属/通孔墙，挡住切割裂纹和水汽工艺厂给模板，你按规则画通常 10~30µm 宽，不许走信号
Bond pad（焊盘）对外打线的金属块，常见 60~80µm 见方IO 库提供下方不能有有源电路，要放 ESD
Scribe line（划片道）芯片之间的切割通道，放测试结构工艺厂规定宽度算 die 面积时不算，但算晶圆片数时要算

这些通常由顶层集成者负责，做 block 的人不用画。但你必须知道它们存在，因为两个原因：

  1. 它们占边缘空间。 seal ring + pad 一圈通常吃掉 50~100µm 的边长，算可用面积时不能算进去。
  2. 它们会影响 DRC。 seal ring 的图形密度很高，如果它离信号线太近，会在边缘产生间距违例，这些违例在 block 级看不到，集成时才爆出来。

边缘空间值多少钱，算一次就清楚。一个 2mm × 2mm 的 die，面积 4.0mm²。四周各留 100µm 给 seal ring 和 pad，可用区变成 1.8mm × 1.8mm = 3.24mm²：

面积损失 = (4.00 − 3.24) ÷ 4.00 = 19%

将近五分之一的面积花在"外壳"上。这也是为什么 IO 数量和 pad 排布要在 floorplan 阶段就定下来——临时加两个 pad，可能要重排整个边缘。

Seal Ring密封环点击看解释

沿芯片四周布置的一圈多层金属与通孔结构，从衬底一直连到顶层，作用是阻止切割产生的裂纹进入电路区，并阻挡水汽。
它不是电路的一部分，但没有它，芯片的封装良率会明显下降。

前八项工具自带，后两项（LVS、ERC）通常要第三方工具加工艺厂提供的规则文件（deck）。这就是为什么"跑通了流程"和"能送厂"是两件事。

DRC 和 LVS 的区别，值得单独记住：

DRCLVS
查什么画得合不合法（间距、宽度、密度、via 规则）版图提取出的电路，和网表是否一致
错了会怎样工厂拒收，根本不制造工厂收货，但做出来功能不对
谁更致命制造不出来做出来是坏的，还查不出来
工具工具内置 DRC / CalibreCalibre / PVS + LVS deck

一句话：DRC 错是"造不出来"，LVS 错是"造出来是废的"。

LVSLayout Versus Schematic，版图与原理图一致性点击看解释

从 GDS 里"提取"出版图对应的电路（有哪些器件、怎么连），再和原始网表逐器件、逐节点对比。
不一致意味着版图和设计意图不同——多连一根线、少一个接触孔、器件尺寸错了，都属于 LVS 错误。

ERCElectrical Rule Check，电气规则检查点击看解释

检查版图上的电气连接是否安全：有没有闩锁路径（latch-up）、有没有浮空的栅极、阱和衬底有没有正确接电源地。
DRC 管几何，LVS 管连接关系，ERC 管电学安全性。三者都过，版图才算干净。

交付物：给工厂和给下一个人

交付物分两类，很多人只准备了第一类。

给工厂（造芯片用的）：

文件说明必需性
GDSII 或 OASIS最终版图。OASIS 体积小很多（常见压缩到 GDS 的 1/5~1/10），大设计首选必需
layer map 文件告诉工厂每个 GDS 层号对应哪一层物理层必需

天线报告证明没有栅氧击穿风险必需

给下一个人（继续做 ECO、做板级、做测试的）：

文件谁要用说明
DEF后端布局布线信息，能重新打开继续改

SPEFSTA真实寄生 RC，签核精度的基础
SDCSTA约束，没它时序报告没法复现

README所有人最容易漏、最有用的一份

README 里必须有的六项：库与工艺版本、工具版本、签核 corner 与模式、waiver 清单及理由、已知问题、复现命令。

那份 README 为什么最重要

半年后有人要在这个设计上做 ECO，他需要知道：用的是哪个库版本、哪个 corner 签的核、哪些违例被 waiver 了、哪条路径是已知问题。

没有这份说明，他要花两周重新摸一遍；有的话，半天能上手。

一个具体场景：ECO 时发现 hold 差 20ps，你插了一个 delay cell，结果时序更差——因为原设计在 ss corner 签核，而你按 tt 在算。README 里写了 corner，这个错就不会犯。

07

我们的环境能做到哪一步

诚实说明。课程环境是 Synopsys 单工具链加开源 45nm 库，能做到的和真实项目差得很远：

环节我们能做到缺什么
filler / tap / endcap命令可跑，能填满—
metal fill命令可跑，能铺完整密度检查 deck 要工艺厂给
seal ring / pad不做需要 IO 库和工艺厂模板
DRC工具内置 DRC 能跑到 0签核级要 Calibre + 工艺 deck
LVS做不了需要 Calibre/PVS + LVS deck + 器件提取规则
GDS 导出可 write_gds缺标准单元和 IO 的完整 GDS，合并出来的版图不完整

所以在课程环境里，你的目标是把流程和判据搞清楚：知道收尾有四件事、每件事为什么做、十项检查的判据是什么、交付物分几类。

真实项目里你会看到的是：Calibre 跑一次 LVS 几十分钟、DRC 报告几万行、density 检查按窗口出热图、seal ring 由工艺厂的脚本生成。这些工具和数字，等你有完整 PDK 的环境再补。

判断自己"会不会做收尾"，不看能不能跑命令，看两件事：拿到一份红色报告，能不能说出它属于十项里的哪一项、判据是什么、该找谁改。命令换个工具就变，判据是稳定的。

08

工作中怎么用：ChipFinish 在项目里的位置

谁做：顶层集成者或收尾专职工程师。做 block 的人一般只负责到自己 block 的 filler 和 DRC，seal ring、pad、全芯片 LVS 都在顶层做。

输入是什么：DRC 归零、时序过线的数据库，工艺厂给的 DRC/LVS deck、密度规则、seal ring 模板、IO 库。

输出交给谁：两个方向。给工厂的是 GDS/OASIS 加一堆报告，走商务和流片流程；给同事的是 DEF/网表/SPEF/SDC/脚本/README，走日常协作。

评审看什么：十项检查逐项签字，任何一项红都要有书面说明。评审最反感的一句话是"跑过了，没细看"——因为 LVS 不对的芯片会被造出来，钱照付。

做错会怎样：轻则返工一周（补 metal fill、重跑 DRC、重出 GDS），重则掩膜报废。一套 40nm 掩膜的价格在百万人民币量级，所以收尾阶段"慢一点、查两遍"是划算的。

自测：先自己想，再点开答案
ChipFinish 收的是哪四件事？
填补（filler/tap/endcap）、铺平（metal fill 密度）、包壳（seal ring 与 pad）、验证与交付（DRC/LVS 与文件包）。
filler 为什么必须从大到小填？
先放小块会把大空隙切碎，大尺寸 filler 再也放不进去，单元数暴涨；遇到障碍物时还会留下小于最小 filler 宽度的窄缝，导致阱不连续。先大后小能一次填满、块数最少。
metal fill 的作用是什么？为什么它会影响时序？
让每层金属密度在每个窗口内达标，保证 CMP 后表面平整，否则后层光刻失焦。填充金属会引入额外耦合电容，靠近关键路径时会把延迟拖大，所以要用 timing-aware 模式避开。
-timingAware 的取舍是什么？
它避开关键网络和时钟，时序安全，但跑得慢、密度可能不达标要迭代；不感知的普通 dummy 快、密度容易达标，但可能把 WNS 拖差几十 ps。按剩余时序余量选。
DRC 和 LVS 的区别是什么？哪个更致命？
DRC 查"画得合不合法"，LVS 查"版图提取的电路与网表是否一致"。DRC 错工厂不收货；LVS 错工厂收货但芯片是坏的，所以 LVS 错更致命。
送厂前十项检查里，哪几项课程环境做不了？为什么？
LVS、ERC（缺 Calibre/PVS 和工艺 deck）、seal ring 与 pad（缺 IO 库与模板）、签核级 DRC（只有工具内置 DRC）。课程环境能做的是 filler、metal fill 命令、内置 DRC 和 GDS 导出。
交付物里给工厂和给同事的有什么不同？
给工厂的是制造必需：GDS/OASIS、layer map、密度/DRC/LVS/天线报告、pad 坐标；给同事的是可继续工作的东西：DEF、网表、SPEF、SDC、SDF、脚本和 README。
为什么 README 是最重要又最容易漏的交付物？
它记录库/工艺/工具版本、签核 corner、waiver 清单、已知问题和复现命令。没有它，接手的人要重新摸两周；有它，半天能上手，也能避免在错误 corner 上做 ECO。
