TCL 第 2 讲 · 变量与替换规则（TCL 的灵魂）

Tcl 2 - Variables & Substitution

set 定义变量、$ 取变量、[ ] 执行命令、{} 和 "" 分组——三种替换是全课程最重要的一讲。还有特殊变量名的 ${} 包裹写法、set 一次只能定义一个变量的字典解法。掌握这一讲，后面所有语法都豁然开朗。

01

定义变量：set 命令

本章目标会用 set 定义三种类型变量；建立"名字绑一个值"的心智模型；说清 {} "" [] 三种符号各自做什么；会用 ${} 调用特殊变量名；会用字典写法装多份信息。

语法：set 变量名 变量值

心智模型（文档原话）

变量就是一个名字绑一个值——名字给你看，值给机器用。比如定义一个人 person，名字叫张三：person 是我们（人）用的名字，"张三"是机器存的值。

示例：

Tcl 练习台多行编辑，点「运行」或按 Ctrl+Enter 执行
stdin 输入
Ctrl / ⌘ + Enter
浏览器内置 Tcl 解释器：set / puts / expr / incr / append / 数组 / 列表 / if·while·foreach·for / proc 都能真跑。支持多行代码，{} 可把换行当分隔符。

命名规则：变量名由字母、数字、下划线组成，建议见名知意（如 age、user_name），避免特殊字符（下划线除外）。

02

TCL 的三种"替换"——一句话原理（文档原文）

一句话原理

{}（不读变量）和 ""（读变量）是同一类——分组（把空格/换行粘成一个词），区别只在于"里面做不做替换"；[] 完全是另一类——替换（先跑命令，用结果把自己顶掉）。

符号叫什么干什么Python 类比
$变量名变量替换把变量的值取出来放进去直接写变量名
[命令]命令替换先执行命令，用结果替换整个 [...]表达式的返回值
{...}分组把一段内容"原样打包"，不读变量原始字符串 r"..."
"..."分组打包，但会做变量替换f-string

特殊变量名：用 ${} 包裹（很少用，但要会）

当变量名里含特殊字符（如 .、-）时，定义照常，调用必须用 ${变量名} 包裹，否则 TCL 解析失败：

stdin 输入
Ctrl / ⌘ + Enter

看一眼错误示范（练习台里跑跑看，报错也是真实的）：

tcl
puts $a.1;# 错误！TCL 会解析为变量 a + 字符串 ".1";# 报错：can't read "a": no such variable
常见坑 · $a.1 不报语法错，但读的是另一个变量

$a.1 不读 a.1，而是读变量 a 再拼上字符串 .1。变量 a 不存在，所以报 can't read "a": no such variable。看到这个报错，先想想是不是变量名里有特殊字符没用 ${}。

06

动手练

动手本讲练习（2 题）
  1. 定义变量 user_name、age，用一条 puts 同时打印它们。
  2. 解释为什么 puts {age=$age} 不会输出变量值。
自测
练习 1 的写法？
set user_name "Tom"、set age 25，然后 puts "user=$user_name age=$age"。
练习 2 的答案？
因为 {} 是"不读变量"的分组，里面的 $age 不会被替换，会原样输出 age=$age。想读变量改用双引号 "age=$age"。
[expr {1 + 2}] 里的方括号是什么机制？
命令替换：先执行里面的命令，用结果替换整个 [...]。
过关标准（都能做到才算学完）
  • 能不看示例写出 set + puts 的定义与打印
  • 能解释 {} "" [] 三种符号的区别
  • 变量名含特殊字符时知道用 ${} 调用
