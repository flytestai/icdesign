双重图形化：为什么两条线分开了仍会报错

Double Patterning and Mask Conflicts

区分 LELE 与 SADP，理解同色间距、奇环、过孔和边界规则，并用布线检查与签核交叉验证。

预计学习 ≈14 分钟 课表学时 0 光刻双重图形化布线DRC
01

先判断规则针对哪种工艺

这一讲在流程里的位置

双重图形化 · 承接 DRC 与签核。先进工艺的底层金属要分两次曝光。本讲解释同色间距和奇环怎么产生，以及为什么"形状对"不等于"能着色"。

原创专题

本讲按钉钉目录第 20 项的主题编排。解释、排查流程和自检均为原创，不使用原文、原图或项目参数，也不假设任何具体工艺采用双重图形化。

当相邻图形太密、一次曝光难以稳定分辨时，可以分步骤形成图形。LELE（Litho-Etch-Litho-Etch）把图形分到两组，分别光刻和刻蚀；两个掩模组之间的叠对误差也需要控制。SADP（Self-Aligned Double Patterning）先形成芯模，再利用芯模侧壁的间隔层生成密集图形，线端通常还要由工艺规定的切割或阻挡图形限定。两者的约束并不相同；SADP 不是任选两张等价的掩模给线段轮流着色。面对 marker，先依据 PDK 确认制造层、图形类型、规则版本及适用工艺，再决定用着色还是几何规则来解释，不能从布线图的显示颜色猜工艺。

02

同色间距与奇环是怎么来的

在简化 LELE 模型里，把每个参与分解的图形记为顶点，把「虽然达到普通间距，但不能同色」记为冲突边。选一处起点，为相邻顶点交替分配颜色；如果沿不同路径到同一顶点时必须赋两种颜色，检查中间是否围成奇数环。任何奇环都不可能二着色，单独交换一条线的颜色只能把冲突移到别处。反过来，没有奇环只能证明无固定颜色的二着色图可解；若边界上有预先指定的颜色，还要检查它们是否满足路径上的奇偶关系。

两种距离阈值要分别看：低于普通间距时，异色也不能修复，必须改几何；达到普通间距但低于同色间距时，异色才是一个候选。达到同色间距则不需要这条冲突边，不过离它很近的第三个图形仍可能限制取色。常见修法是挪线、改轨或改变走线路径以移除冲突边。把一个图形切成可异色的两个片段需要拼接，只在规则明确允许、并能满足重叠、位置和邻近限制时考虑；它不是普通着色操作，也不等同于把电气连通人为切断。

03

从 marker 重建冲突子图

从一份布线后布局快照出发，固定图层映射、签核规则文件版本、放置和宏边界方向，并保留相邻块的图形与固定掩模信息。实验选择一个简化 LELE 局部窗口：只演示三块彼此独立的同层金属图形，普通最小间距取 40 nm、同色最小间距取 80 nm；等于门槛视作通过。距离用轴对齐矩形间的最短欧氏边缘距离。这些数值、坐标和测距定义均为虚构教学输入，不代表 PDK 或真实报告，不可作为布线命令执行。实际规则可能区分方向、线端和平行段长度，不能把本例的单一距离门槛移用到项目。

04

只改一处支线，切断一条冲突边

保留 A、B 与所有固定图形，选择可重布的 C，把局部矩形从 x=45..85, y=90..130 移到 x=90..130, y=112..152，以模型里允许的站位为前提。真实实现中，不能只修改三块孤立图形的坐标：C 对应的支线仍需保持原网表端点，新的接入段、线端和过孔也进入检查窗口。先在合法的增量布线上尝试该候选，再从更新后的版图重新找邻居。若工具仅报告原 marker 消失，而未检查新位置，不足以说明问题解决。

C–A 的距离是 sqrt(50² + 72²) ≈ 87.66 nm，已跨过 80 nm 门槛；B–C 仍需异色。A 与 C 现在可以同为 M0，并不是因为两者连网，而是因为不再有不同色约束。在这个子图里，两条冲突边仍在，但它们都满足分配条件。检查差异时应分别列出保留、新增和删除的边，不能要求「没有冲突边」才算通过。若拼接后发现另有固定 M0 的邻块图形与 C 必须异色，当前赋色就失效，必须按扩大的连通组件重新求解或改走线。

05

过孔和拼接边界要放进同一轮检查

定位 marker 时同时查看过孔切割层、上下金属包围和线端，确认报的是金属同色间距、几何间距，还是 SADP 的切割或阻挡约束。过孔阵列可能受独立的掩模和间距要求；金属着色通过不是过孔自动通过。检查窗口应跨过宏、模块与相邻单元的边界，纳入两侧固定颜色、拼接后方向和相邻图形。两个模块各自通过不等于拼接通过，例如翻转后新近邻可能改变冲突路径的奇偶关系，也可能直接产生异色都无法修复的几何间距违例。基础操作见 Route 和 布线后优化。

06

实现检查和签核分开验收

先用支持对应规则的布线器做局部增量检查，把优化前后的 marker、图形坐标、掩模指派和相关网络归一到同一图层映射。再用相应 PDK 的签核规则复查拼接后的版图，结合规则名称、坐标和触发图形核对实现检查的差异。实现工具没报不代表签核通过；若两个工具的结果不一致，先查规则版本、检查范围以及颜色数据是否随版图完整传递，而不是删标记。对新增或移动的线、过孔，还要重新检查连通性，更新寄生后核对相关路径时序，并确认邻网未产生新问题。

07

候选方案值不值得保留

  • 进入下一步： 原奇环被打断、可着色分配符合固定掩模、没有新增几何或过孔违例、签核规则在拼接版图通过。原端点连通无误，时序符合项目门限，才能保留候选走线。
  • 拒绝候选： 挪线后若新增另一条冲突边构成新奇环，或让线端、过孔、宏边界检查失败，不在失败走线上继续叠加改色。先保存对应 marker 和触发图形，恢复原布线快照、掩模数据和配套寄生，然后按同一规则复跑基线确认问题可复现。
  • 下一次只换一个变量： 可以试另一条合法轨道或更短接入；若考虑拼接，先检查 PDK 规则和支持能力。比较候选时同时记录是否保住端点、用了多少新过孔，以及受影响路径的余量，不以单个 marker 消失作为唯一取舍条件。
08

三条线能用两种颜色吗

自测
A、B、C 两两不能同色，只给 B 换色能通过吗？
不能，三条边构成奇环。移开 C 使其与 A 达到同色门槛，才可能删除 C–A 边，让 A、C 同色。
为什么三对普通间距都通过，仍会报分解冲突？
每对距离都至少 40 nm，却小于 80 nm 的同色门槛，三对都必须异色；两个掩模不能满足奇环。
规则只在两个宏拼接后才触发，先查什么？
确认拼接方向、边界两侧的固定掩模与图形间距，以及过孔和切割约束；在拼接版图上使用对应签核规则复查。
09

没有奇环，为什么仍过不了着色

模拟拼接分解报告（非 PDK 数据）。 简化 LELE 模型中，普通间距至少 40 nm，同色间距至少 80 nm；已列出所有可能形成约束的邻接对，其余距离都不小于 80 nm。左右子块边界 P、Q 均是已冻结的 M0 预着色图形，形状与掩模都不可改；只有顶层支线 X、Y 可重布。

text
模拟邻接距离(nm)     P–X    X–Y    Y–Q    X–QT0 拼接基线          55     64     58     96T1 仅 Y 换轨         55     64     86     96提议 T2：保持 T0 的距离，但把固定图形 Q 改成 M1。

先独立交付。 从距离重建 T0 的异色边，按 P 的颜色推导到 Q，写出见证链。给 T1 写一份可核对的掩模指派，并分别判断 T1、T2 是否有资格提交签核。不能移动或改色冻结图形以配合自己的解。

标准判断。 T0 的 P–X–Y–Q 是一条三边路径，不是奇环；三次换色要求两端不同色，而它们都被钉在 M0，因此无解。T1 让 Y–Q 达到同色间距，移除这条边，可取 P=M0、X=M1、Y=M0、Q=M0，因此可提交签核，但尚未签核通过。T2 虽能消掉数学冲突，却违反冻结约束，直接拒绝；也不能靠忽略固定颜色再把子图报成通过。

验收与回退。 对照顶层版图导出确认两侧冻结形状和掩模均未变，在拼接窗口重跑分解、几何与过孔检查，并核对相关网络连通和时序。若换轨引入新邻接或固定数据丢失，撤回顶层走线及配套寄生、恢复 T0 并保留冲突记录；不回写子块预着色数据。
