Calibre DRC：手修与复查

Calibre DRC Debugging

从签核标记追到版图几何，排查间距、filler 短路和 ECO 后成批短路，并验证修复。

预计学习 ≈4 分钟 课表学时 0 CalibreInnovusDRCLVSECO
01

从 Marker 定位到可编辑对象

课程来源

本讲是网站原创专题；钉钉目录第 13 项仅用于确定主题与顺序，不转载原文、项目参数或图片。相关基础可另看上传 Word 整理的 ECO 短路、开路和 DRC。

Calibre DRC 用规则集检查版图几何；LVS 把版图提取出的器件和连接与源网表比较。没有几何违例不能证明接线正确。打开签核结果，先记录规则名、标记坐标、所涉层、实例层次及出现次数，再核对签核流出的版图是否与正在查看的 Innovus 数据库同版。Marker 是违规提示，不一定正好盖住可编辑图形；将顶层坐标映射到实例后，确认旋转、镜像和层映射，再辨别图形来自顶层布线、宏块内部或邻接实例。

02

区分 VIA 和 M1 的间距规则

同一处可能既出现过孔切孔间距，也出现 M1 金属边间距；过孔被金属覆盖的范围不足则是包围规则，不是间距。按报告规则找到参与测量的两处几何，核对测量方向和相邻图形，再决定是移动合法过孔还是调整金属段。改线前先存可回退的数据库，只编辑自己拥有的布线；遇到标准单元或宏内部图形，先确认版本、朝向及邻接条件，不直接改库版图。改完核对网络归属、接入和邻近层，不以标记从界面消失作为修复依据。

03

排查 Filler 与 ecoRoute 后的短路

Filler 用于填补标准单元行空隙，某些类型还会延续电源轨。若短路出现在 filler 边缘，先核对相邻单元朝向、供电域、填充单元类型与电源网绑定；标记靠近 filler 不代表根因必然在 filler。若 ecoRoute 后短路突然增多，保留修前与修后快照，按网络、位置或重复实例归并，优先追查本次变更的连线、供电绑定和布线约束。先在副本验证一个代表点的根因，再决定局部重布或回退；不要批量删过孔或删除填充单元来压低计数。

04

小练习：给出修后验收证据

练习：同一块区域出现一个 M1 spacing 标记和一个电源短路，挪开一段信号线后，布局工具的局部几何检查不再报错。能否认定电源短路也已修复？

答案：不能。几何间距与误连分别需要证据。先查局部电源和信号连通性，确认有没有新开路；再以修后数据库导出同一范围和配置的签核输入，复跑 Calibre DRC 与 LVS。按项目要求做全量签核，对照修前后的规则计数、坐标与受影响网络；只有原违例消失且没有引入新违例或连接差异，才能据此关闭问题。
