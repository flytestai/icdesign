01

列表是什么、两种核心定义方法

本章目标会用 {} 和 list 两种方法定义列表；会用 lindex / llength 读取；会取嵌套列表里的值（两种写法都熟）。

列表是 TCL 中最常用的数据结构，用于存储有序的多个元素（元素可以是字符串、数字、甚至另一个列表），支持增删改查、排序、拼接等操作。对应 Python 的 list。

方法 1：大括号 {} 定义（适合多行元素）

大括号会保留元素的原始格式（如换行、空格），无需转义，空格和换行都是元素分隔符：

动手练

动手本讲练习

用 {} 定义一个多行列表，装 4 个城市名，其中一个城市名带空格；用 lindex 取第 2 个、用 llength 求长度；再用多级连写法取一个嵌套子列表的值。

自测
列表的索引从几开始？
0，和 Python 一样。
两种定义方法怎么选？
多行、保留原始格式用大括号 {}（空格换行都是分隔符，含空格元素套双引号）；单行、嵌套列表用 list 命令（自动处理分隔）。
取嵌套列表第 2 行第 2 列的两种写法？
lindex [lindex $L 1] 1 或 lindex $L 1 1（由外向内）。
过关标准（都能做到才算学完）
  • 能用两种方法定义列表并说清适用场景
  • lindex / llength 不看资料能写
  • 嵌套列表两种取值写法都能写对
