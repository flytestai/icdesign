Linux 第 4 课 · 查看与编辑文件（vi 全套）

Linux 4 - View Files & vi/vim

cat / more / less / head / tail / vi 五种查看方式；vi/vim/gvim 编辑模式与命令行模式全套用法；diff 对比文件；alias 快捷指令；重定向 > 与管道 |；Linux 快捷键；课后练习二。

约 60 分钟 课表学时 2 Linuxcatlessvidiff重定向管道
01

1. 查看文件

本章目标七种方式查看文件；vi 的编辑模式和命令行模式全部记熟；会 diff 对比文件；会配 alias；会用重定向和管道。
text
cat   文件名              # 直接全部输出cat  -n  文件名           # 查看文件，同时显示行号zcat  文件               # 查看压缩文本文件tac   文件名              # 倒着查看文件内容

查看大型文件：

  • more 文件名：字母 b 往上翻页，字母 z 往下翻页，翻到底自动退出，或按 q 退出；
  • less 文件名：和 more 用法一样，但必须按 q 才能退出。

查看文件开头 / 结尾：

text
head  文件名        # 默认查看前 10 行head  -20  文件名   # 查看文件前 20 行tail  文件名        # 默认查看后 10 行tail  -20  文件名   # 查看文件的后 20 行
小技巧

tail -100 xxx.log 看最新 100 行——跑完仿真/PR 第一件事就是它。

02

2. vi / vim / gvim 编辑文件

  • vi：查看文件并且可以编辑；
  • vim：相比 vi 可以做一些高效的配置；
  • gvim：相比较 vim，多了 gui 界面，功能和 vim 一致（还支持打开压缩文件）。

vi 的基本用法：

text
vi  文件名
  • 文件不存在，会创建——但不保存就不会真的创建；
  • 如果有这个文件，就会打开显示内容。

进入编辑模式（左下角会显示 insert）

按键作用
字母 a在光标后面追加（append 模式）
字母 i在光标所在位置插入（insert）
字母 o换行再插入内容

按 esc 可以退出编辑模式（insert 消失）。

命令行模式（按 : 进入）

命令作用
:10快速跳转到第 10 行
:set nu将文件带上行号显示
:set wrap会换行显示
:wq保存并退出
:wq!强制保存
:q不保存退出
:q!强制不保存退出
:set ic搜索的时候忽略大小写
/关键字向下搜索关键字，n 下一个，shift+n 上一个
?关键字向上搜索关键字

对比两个文件的差异

text
diff       文件1 文件2    # 直接打印不同的内容zdiff      压缩文件对比    # 支持 zcat 类压缩格式gvimdiff   文件1 文件2    # 打开两个文件，高亮显示不同的部分

alias 快捷指令

text
alias          # 查看已经设置了哪些快捷指令alias  l       # 查看是否设置了 l 这个快捷指令
03

3. 特殊符号

1）重定向符号 >：把输出写入指定的文件。

text
history  >  1.t                    # 把历史命令写进 1.techo 123 > 2.t                     # 把 123 写进 2.tcat  -n  .bash_history  >  1.t     # 带行号写进 1.t

2）管道符 |：连接两个命令，把前一个命令的输出作为后一个命令的输入。

text
cmd1  |  cmd2ll | grep '.txt'      # 列出内容后过滤出含 .txt 的行
04

4. Linux 的快捷键

快捷键作用
ctrl + L清屏（clear 也可以）
方向键 ⬆️⬇️翻之前/之后的命令
ctrl + a光标移动到开头
ctrl + e光标移动到结尾
命令前加 #不想执行某个命令时，ctrl+a 回到开头加个 # 就变成注释

打开文件后：

按键作用
G跳转到文件最后一行
gg跳转到文件第一行
g + f直接在文件内跳转另一个文件
ctrl + o返回原文件
!100history 之后，直接执行第 100 行执行过的命令

tips：帮助学习 cmd 的使用——cmd --help，展示命令的语法格式以及用法。

动手练：练习二

动手练习二（17 题）

1、进入家目录 2、创建目录 D1（如果有了，先删除） 3、在 D1 目录下创建文件 test01.txt，输入以下内容并保存退出： aaa bbb ccc 4、在 D1 目录下创建目录 D2 5、在 D2 目录下创建文件 test02.txt，输入以下内容并保存退出： aaa ddd ccc 6、对比 test01 和 test02 文件的不同 7、使用 7 种方式查看 test01 文件 8、回到家目录，执行下面的命令，作用是查看 history 执行过的命令然后写入到 1.t： cat .bash_history > 1.t 9、查看 1.t 最后一行 10、在文件中设置行号 11、跳转到文件开头 12、跳转到第 15 行 13、跳转到第 20 行 14、搜索关键字 cd 15、搜索关键字 mkdir 16、编辑 1.t，在最后一行输入： this is test input++++++++++ 17、不保存退出 1.t

自测：先自己想，再点开答案
more 和 less 退出方式的区别？
more 翻到底自动退出、也可按 q；less 必须按 q 才能退出。
vi 里 :q! 和 :wq! 的区别？
:q! 强制不保存退出；:wq! 强制保存并退出。
> 和
分别是什么作用？| > 是重定向，把输出写入文件；| 是管道，把前一个命令的输出交给后一个命令继续处理。
vi 怎么搜索关键字？
/关键字 向下搜（n 下一个，shift+n 上一个）；?关键字 向上搜；:set ic 可忽略大小写。
