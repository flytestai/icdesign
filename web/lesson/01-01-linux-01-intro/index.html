Linux 第 1 课 · 认识 Linux 与行业工具

Linux 1 - Intro & Industry Tools

什么是 Linux、优点、学习目标；工具三件套 VNC / Xshell / MobaXterm；芯片岗位分工与 PR 工具 Innovus / ICC2；后端工程师的工作技能地图。

约 55 分钟 课表学时 2 Linux入门VNCXshellInnovusICC2
01

1. 什么是 Linux

本章目标知道 Linux 是什么、后端为什么离不开它；认识 VNC / Xshell / MobaXterm 三个工具；看懂芯片岗位分工和 PR 工具的两个流派。

Linux 是操作系统的一种。它和我们熟悉的 Windows 有几个关键区别：

对比项WindowsLinux
界面一般都有图形界面一般没有界面（纯命令行）
装软件下载安装包，一路下一步一般通过命令安装
更新经常需要更新一般不需要
用户一般单个用户使用支持多用户同时使用

Linux 系统优点：

  1. 支持多用户、多线程；
  2. 占用资源少，系统稳定；
  3. 开源、免费；
  4. 全球的计算机爱好者共同维护。

本阶段主要学习目标：

  1. 常用的 Linux 命令；
  2. 一些简单的 shell 脚本。
小技巧

EDA 工具（Innovus / ICC2 / PT）每天跑在 Linux 服务器上，所有交互都靠命令行。Linux 不熟，后面每一步都会别扭。

02

2. 关于工具

VNC：远程连接云服务器的桌面（能看到图形界面）。

Xshell：练习 Linux 的工具（个人/学校免费版入口）。

下载地址：https://www.xshell.com/zh/free-for-home-school/

MobaXterm：另一款 Linux 练习工具。

下载地址：https://mobaxterm.mobatek.net/download.html

工作中用到的工具：ETX——课件原文只列了名字。进组后按公司内网环境配置使用，学习阶段把 Xshell / MobaXterm 用熟即可。

03

3. 芯片的相关岗位

芯片行业的岗位链路：

芯片的架构师 → 数字前端 → 数字后端 → 数字验证

  • 前端：主要负责产生 netlist（网表）；
  • 后端：拿到 netlist，开始 PR；
  • PnR / PR：Place and Route，布局和布线。
04

4. PR 的工具（EDA 工具）

两大流派：

工具公司
InnovusCadence 公司
ICC2Synopsys 公司

PR 要同时实现两个方向的目标：

  • physical（物理方向）：短路、断路——foundary 对工艺有约束；
  • timing（时序方向）：延迟要满足要求。
05

5. 工作技能地图

  1. Linux 命令一定要熟练！熟练！熟练！
  2. PR 工具：页面操作、命令操作、简单的 tcl 脚本编写；
  3. PT 工具：时序的修复。
学习顺序

先把 Linux 命令练熟（本阶段第 2-6 课），后面阶段的 Innovus / ICC2 课全都在这个基础上展开。

06

动手练

模拟终端本课先用模拟终端热热身：敲 ls 看看输出，输入 help 看全部可用命令
[autumn@eda ~]$
这里跑的是浏览器里的模拟环境：命令、输出、报错都按真实 Linux 的行为写，练手够用；真机上的路径与权限另有差异。
自测：先自己想，再点开答案
Linux 和 Windows 最显著的差别是什么？
Linux 一般没有图形界面、靠命令行交互，且支持多用户、占用资源少、开源免费。
后端岗位拿到的输入是什么？
前端产生的 netlist（网表），后端据此开始 PR（Place and Route 布局布线）。
PR 的两大 EDA 工具分别来自哪家公司？
Innovus 来自 Cadence，ICC2 来自 Synopsys。
PR 要同时满足哪两个方向的目标？
physical（物理：短路/断路，受 foundary 工艺约束）和 timing（时序：延迟满足要求）。
过关标准（都能做到才算学完）

  • 知道 VNC / Xshell / MobaXterm 各自的用途
  • 能画出 前端→后端 的岗位链路与 PR 的两个目标方向
