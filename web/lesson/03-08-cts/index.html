六、CTS 时钟树综合

1、基本概念

latency: 时钟的传播延迟

skew: 时钟延迟的差值

分为Global Skew（工具更关注）和Local skew

Gs：同一时钟域，任意两个路径的最大skew。CTS阶段工具更关注的是gs，尽可能把gs做小；

Ls：同一时钟域，任意两个有逻辑关联关系的路径最大skew，分析timing时更多关注ls。

什么是NDR： Not Default Routing Rule 非默认绕线规则

针对cts tree的部分的走线单独设置绕线规则， 宽度和间距

2W2S 2倍的宽度width 2倍的间距spacing

2W1S

4W2S

创建ndr的方法

clk gating： 门控时钟， 类似于一个与门，控制时钟信号的翻转，在不需要共做的时候，可以关闭某些path的时钟翻转，达到节省功耗目的

三种特殊的pin的设置

特殊保护的net

shielding

一般使用VSS，打在需要保护的net的上下track上

clock_transtion怎么修复

1、根据rpt的net，找到对应net

2、查看电路图，找到net前后一级的buf，在net中间插buffer

CTS 约束与 Sink 统计

2、CTS的一些约束命令

1、设置某些pin的delay，做长latency或者做短latency

delay为正数，表示要做长，delay为负数，表示要做短

set_clock_balance_points -clock [get_clocks CLK] -delay 50 -balance_points [get_pins U2/CLK]

2、多个不同的时钟做平

create_clock_balance_group -objects {clk1 clk2 clk3} -name balance_group1

3、clone ICG的开关

允许 CTS 通过 clone clock gates 来修复 DRV

set_ccopt_property clone_clock_gates true

允许 CTS 通过 clone clock gates 来缩短 delay

set_ccopt_property clustering_clone_cells_to_reduce_balancing_conflicts

true

获取sink点的信息

得到所有 clock tree 的名字

get_ccopt_clock_trees *

得到 HCLK 的所有 sink 名字

get_ccopt_clock_tree_sinks * -in_clock_tree HCLK

获取test_clk的sink点数量

llength [get_ccopt_clock_tree_sinks * -in_clock_trees test_clk]

实现一个脚本 count_sinks.tcl, 写完之后可以source count_sinks.tcl

1.0版本

自动统计出所有的clk的sink点数量

输出以下 结果：

my_clk is .... sinks

div_clk is ...sinks

test_clk is ... sinks

2.0版本

自动根据clk数量不同，自动统计每个clk的数量

03

CTS 后检查与延迟调整

3、cts之后的check

1、检查drv的情况

report_ccopt_clock_tree

2、检查latency是否达到要求（重点检查部分）

target_latency DCLK 850ps

target_skew

如果latency低于target latency， 需要垫tree

如果latency高于target latency 需要分析为什么latency变得这么长

3、检查setup和hold （可选， 可以放到optcts再检查）

此时clock不是idea的，是真实的，需要检查hold

分析的思路：

1、找到最长的path， highlight 这条path， 看是否有dutor的情况 要不就是有兜圈，要不就是物理距离很远

2、查看latency的rpt(rpts/clock_latency.rpt.gz)， 分析哪一段delay很大， 例如netdelay 很大

3、查看path上是否是插了很多buf，导致delay叠加， 可能约束不合理，太严格导致

调整latency的方案：

使用手动bound sink的方法，适用于物理距离太远的情况

使用该命令可以做短latency

set_clock_balance_points -clock [get_clocks CLK] -delay -200 -balance_points [get_pins U2/CLK]

报latency的命令

report_clock_timing -type latency -clock FCLK -nosplit

时钟的频率

时钟的频率和时钟的周期是倒数关系

时钟频率 = 1/时钟周期

已知时钟周期是1000ps ,计算时钟的频率

频率 = 1s/1000ps 1s=1x10的9次方ps

1Ghz = 1000Mhz

通用 ECO 操作

4、通用的ECO

插入一个buffer或者inv

ecoAddRepeater

-cell buf名字

-loc 插入的buf的物理位置

-name buf的实例名字 类似 fix_drv_0308_01 含义： 在3月8日，为了修复drv问题插入的第一个单元

-net 在哪根net上插入单元

-newNetName 插入单元连线的名字

-term 在某个pin上插入单元

删除一个buf或inv

ecoDeleteRepeater

-inst {<inst1> <inst2>} 要删除的单元的ins名字

-invPair 删除成对的inv

更换一个buf或者inv或cell

ecoChangeCell
