;# 1. 定义数据（列表 + 嵌套）
set mem_list {
    I_CONTEXT_MEM/I_CONTEXT_RAM_0_4
    I_CONTEXT_MEM/I_CONTEXT_RAM_0_3
    I_CONTEXT_MEM/I_CONTEXT_RAM_0_2
    I_CONTEXT_MEM/I_CONTEXT_RAM_0_1
}

;# 2. 定义函数（proc + 参数 + return）
proc report {mem idx total} {
    puts "进度：$idx / $total —— 正在处理：$mem"
    return 0
}

;# 3. 循环处理（foreach + llength + 命令替换）
set total [llength $mem_list]
set idx 0
foreach mem $mem_list {
    incr idx
    report $mem $idx $total
    change_selection [get_cells $mem]
    move_objects -delta {-50 0}
}

;# 4. 结果统计
puts "全部 $total 个单元处理完毕"

10.2 结课自测（覆盖全部知识点）

每题先自己作答，再点开看参考答案：

自测：先自己想，再点开答案
环境类：innovus 打不开怎么办？win / exit 是干什么的？
打开 ~/.bashrc 增加 source /opt/cadence/cds.sh 等工具脚本行，然后 source .bashrc 重新加载。win 打开 Innovus 版图窗口；exit / close 关闭。
变量类：set a.1 100 后如何正确调用它？
用 ${a.1} 包裹调用。直接写 $a.1 会被解析成"变量 a + 字符串 .1"，报错 can't read "a": no such variable。
append、incr、expr 各解决什么问题？整数除法的坑是什么？
append 做字符串追加拼接；incr 做整数递增/递减（默认 +1，负数为递减）；expr 做数值运算。坑：整数除整数结果还是整数（5/3=1），想得到小数至少一边要写成浮点数（5.0/3）。
数组类：array set 第一个参数有什么限制？unset 数组(键) 和 unset 数组的区别？
array set 第一个参数必须是不带括号和 key 的纯数组名。unset 数组(键) 只删除单个元素（再访问报 no such element in array）；unset 数组 删除整个数组（再访问报 no such array）。
列表类：lappend 和 lreplace 谁改源数据？lsort 排数字要加什么参数？
lappend 直接修改源数据；lreplace 不修改源数据（返回新列表，需要 set 接住）。lsort 排数字必须加 -integer（默认是字符串字典排序），降序加 -decreasing。
取嵌套列表第 2 行第 3 列的两种写法？
① 双层写法：lindex [lindex $class_list 1] 2；② 多级连写：lindex $class_list 1 2（由外向内）。
if 的四大语法铁律？
① } 和 elseif/else 同行且中间有空格；② 条件必须用 {} 包裹且 { 不能换行；③ 全部用英文半角符号；④ TCL 严格一行一条命令，不能用换行切开 if 命令。
while 三要素是什么？缺了哪个会死循环？
初始化 → 判断 → 更新。缺了"更新"（如 incr i）就死循环；另可用 while {1} + break 做无限循环。
args 必须写在参数列表什么位置？
必须写在参数列表最后；只有 args 时表示可传 0、1、任意多个参数，args 把传入参数打包成一个列表。
proc 不写 return，返回什么？
返回最后一条命令的结果。
