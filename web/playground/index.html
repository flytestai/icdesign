代码练习场（Linux + Tcl）

按课程顺序练：Linux 命令跑在模拟终端里，Tcl 代码直接执行。左边写、右边看输出，报错行为与真实环境一致。

练习顺序 = 课程顺序：Linux 第 2–6 课 → Tcl 第 1–10 讲
Linux 命令（一行一条，按顺序执行；# 开头是注释）
交互终端自己敲命令、回车就执行；↑↓ 历史、Tab 补全
[autumn@eda ~]$
和左边共用同一个环境：点「跑整段」等于把左边逐条敲进来，之后你可以接着改、接着试。想从头来就点「重置环境」。
Tcl 交互解释器一行一执行；括号没闭合会自动等续行
tclsh>%
变量和 proc 都留在环境里：先 set 一个变量，下一行直接用它；多行结构（if / while / proc）写到一半回车会显示 ...> 等续行。
stdin 预输入（每行一条，供 gets stdin 读取）
