常见问题

需要什么基础？

会开机、会用浏览器就行。Linux 从"什么是终端"开始讲；数字电路的基本概念会在阶段二补。阶段一的 Linux 课自带浏览器内模拟终端，不装环境也能练。

要装什么软件？

课程实验跑在一台 Linux 服务器上，浏览器里给命令、给解释、给预期输出；本机只需要一个 SSH 客户端。前面几个阶段的练习用页面里的模拟终端就能做完。

学完能做什么？

能独立走完 综合 → 布局 → 时钟树 → 布线 → 时序签核 这条链路，看得懂每份报告，知道违例从哪来、怎么修。

为什么英文字母这么多？

行业里就是这么叫的，改不了。所以每个术语第一次出现都给中英对照卡，点开有白话解释；全部术语还汇总在术语表里。
