命令速查

Tcl 常用命令一页查：变量、运算、数组、列表、流程控制、函数、输入输出。

变量与输出

功能写法
赋值set x 5
取值$x（特殊变量名用 ${a.1}）
打印puts $x / puts "a=$x"
追加append x "!"
递增递减incr i / incr i -3
删除unset x / unset arr(k) / unset arr
注释行中 ;#、行首 #
分组规则"" 读变量；{} 原样；[cmd] 命令替换

运算

功能写法
四则运算expr {$a + $b}
整数除法陷阱expr {5/3} → 1；要小数用 5.0/3
取余expr {$i % 2}
比较expr {$x >= 80}
逻辑expr {$a > 0 && $b > 0}、||、!
随机数expr {rand()}（0~1 不含 1）、expr {int(rand()*100)}

数组（键值对）

功能写法
单个赋值set student(001) "Xiao Ming"
批量赋值array set person {name zhangsan age 20}
取键列表array names person
取键值对array get person
键值对个数array size person
取嵌套字段dict get $person(001) name

列表

功能写法
定义set l {a b c} / set l [list 1 2 3]
取元素lindex $l 2（多级：lindex $L 1 1）
长度llength $l
末尾追加（改源）lappend l x y
替换（不改源）lreplace $l 1 2 apple
查索引lsearch $l 3（找不到 -1）
排序（不改源）lsort -integer -decreasing $l
拼接concat $l1 $l2
拆分 / 粘合split "a,b" , / join $l -

流程控制

功能写法
条件if {$x >= 90} { ... } elseif {...} { ... } else { ... }
当循环while {$i < 5} { ... incr i }
遍历foreach x $lst { ... }（双变量：foreach {k v} $pairs { ... }）
计数for {set i 0} {$i < 5} {incr i} { ... }
跳出 / 下一轮break / continue
无限循环while {1} { ... break }
加载脚本source 文件

函数

功能写法
定义proc name {a b} { ... return $v }
默认参数proc f {a {b 5}} { ... }
可变参数proc f {args} { ... }（必须放最后）
调用f 1 2，取返回值 [f 1 2]
全局变量函数内先 global x
返回值return $v；不写则返回最后一条命令结果

常见报错速查

报错信息原因解决办法
can't read "a": no such variable用 $a.1 调用含 . 的变量名，被解析成变量 a用 ${a.1} 包裹调用
can't read "student(002)": no such element in array数组元素已被 unset 删除重新 set 赋值后再用
can't read "student(001)": no such array整个数组已被 unset 删除重新定义数组
死循环（程序卡住不动）while 缺了"更新"要素检查循环体内有没有 incr i 等更新语句
if 语法错误 / 命令提前结束} 和 elseif 不同行、条件没用 {}、用了中文符号检查四大铁律（第 7 讲）
array set 报参数错误第一个参数带了括号（如 person(001)）只写数组名，键放 {} 里
