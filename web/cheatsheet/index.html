按工具分组的常用命令。写脚本时不用翻课文，搜这一页就够。

## Linux：文件与目录 {#linux-file}

命令作用常用写法
pwd我在哪个目录pwd
ls列出目录内容ls -l（详细）ls -a（含隐藏）ls -lh（人读大小）
cd切目录cd ~（回家）cd ..（上一层）cd -（回上一个目录）
mkdir建目录mkdir -p a/b/c（逐级建）
cp复制cp -r dir1 dir2（递归）
mv移动/改名mv a.tcl b.tcl
rm删除rm -rf work/（危险，确认再敲）
cat看整个文件cat file.log
head / tail看头/尾head -n 20 f tail -n 50 f tail -f f（跟读日志）
chmod改权限chmod +x run.sh chmod 755 run.sh
find找文件find . -name "*.rpt"
du / df目录大小 / 磁盘剩余du -sh * df -h

## Linux：文本处理（后端最常用的四个）{#linux-text}

命令作用例子
grep按内容找行grep -n VIOLATED timing.rpt（带行号）grep -c（计数）grep -v（反选）grep -i（忽略大小写）
sed替换 / 取行sed 's/old/new/g' f sed -n '10,20p' f
awk按列取数awk '{print $1, $3}' f awk -F: '{print $1}' f awk '$2 < 0'
sort / uniq排序 / 去重sort -k2 -n f sort -nr f uniq -c
wc计数wc -l f（多少行）
cut按分隔符取列cut -d/ -f2 f
tr字符转换tr a-z A-Z
小技巧

a | b = 把 a 的输出当作 b 的输入。后端读报告几乎都是这个套路：

bash
grep "slack" timing.rpt | awk '{print $3}' | sort -n | head -3# 取出所有 slack 值 -> 按数值排序 -> 看最小的三个
