缩写解码表

PR 里那些三字母缩写，按"你在哪一步遇到它"分成七组：角色、流程、文件、时序、物理、单元、工具。每条一句话讲清它在流程里扮演什么角色，不是词典式定义。

怎么用这一页

这一页不是术语词典（要看完整解释去 术语表），它解决的是另一种卡顿：同事说了一串缩写，你听懂了每个字母，但不知道它在流程里是干什么的。

三点用法：

  1. 按"你卡在哪"跳组：听人聊天听不懂→第一组；不知道下一步跑什么→第二组；收文件不知道哪份是哪份→第三组；时序报告看不懂→第四组；route 绕不通→第五组。
  2. 每条只记"角色"，不记全称。全称是给简历和文档用的，工作里你只需要知道它占哪个位置。
  3. 每组标题下都标了出处课，想深挖点链接回去读那一讲。

最容易混的六对

这六对是新人问得最多的，先分清再往下看。

一对区别一句话
LEF 与 DEFLEF 描述"长什么样"（单元/工艺的规格，全项目通用）；DEF 记录"这次摆在哪"（本设计的实际坐标，一人一份）
lib 与 rc techlib 管 cell 延迟（晶体管快慢）；rc tech 管 线延迟（导线寄生 RC）
pin 与 portpin 在 Cell 层（单元身上的引脚）；port 在 Block 层（模块对外的端口），位置由 Top 指定
WCS 与 BCFWCS = 最慢条件，查 setup；BCF = 最快条件，查 hold。记反了报告全绿但芯片是废的
S1 与 S2S1 是纯功能网表（用来估面积）；S2 是带 scan 的网表（门数涨 20%~100%，真正要做的版本）
PV 与 PAPV 是 Physical Verification（DRC/LVS/天线）；PA 是 Power Analysis（IR drop/电迁移）。同在 ECO 阶段，修的东西完全不同

一、角色：你在跟谁打交道

出处：什么是布局布线（PR）、SDC 时序约束

缩写全称 · 中文它在流程里是什么
PR / PnRPlace and Route · 布局布线把网表变成版图的那段活，也就是本课程的主体
PDPhysical Design · 物理设计"后端"的正式叫法；PR 是 PD 的主战场
DEDesign Engineer · 前端设计写 RTL、做综合、交网表给你的人。逻辑太深摆不下去，就找他改代码
MEMiddle End Engineer · 中端夹在前后端之间：做 DFT、formal、MMMC 环境，网表也常从他那儿出
AEApplication Engineer · 应用工程师工具厂商派到项目上的技术支持，内部命令不懂就问他
FCTFull Chip Timing · 全芯片时序写 SDC 的部门。约束不合理要提给他们改，不能自己偷偷改一版
Top顶层整个芯片那一层，负责给各 block 下发边界、port 位置和约束
Block模块你实际负责的那一块，有明确物理边界，接口由 Top 定
Fabless无晶圆厂设计公司只设计不生产，把制造交给 foundry
Foundry晶圆代工厂台积电、中芯这类，卖的是产能和工艺
IDMIntegrated Device Manufacturer自己设计自己造，如 Intel

二、流程：一天到晚在跑什么

出处：PR 全流程九步

缩写全称 · 中文它在流程里是什么
init初始化 · 导入设计把网表、lef、lib、sdc 吃进工具，建立初始数据库
floorplan / FLP布局规划定 die 面积、摆 mem/macro、加物理单元；全流程里手动活最多的一步
powerplan供电规划打电源网络（VDD/VSS），先有电才能摆单元
place布局工具自动摆几百万个标准单元，人只给密度和约束
CTSClock Tree Synthesis · 时钟树综合专门绕时钟线，让时钟同时到达所有触发器
optCTS时钟树优化CTS 做完时序通常更差（多了 buffer），这一轮专门修
route布线把所有信号线真正连起来，目标是 open 与 short 清零
optRoute / OBT布线优化 · 流片前优化同一件事的两个名字：真实 RC 下修最后的时序与 DRC
chipfinish收尾出 GDSII，做交付前的清理与检查
preCTS opt布局优化place 之后、CTS 之前那一轮，用估算时钟修 setup
FINAL PR终版 PR反复跑多个 run 后选定的那一版，之后只能走 ECO
ECOEngineering Change Order · 工程变更版图定死后的小修：改一根线、换一个 cell，不能挪 memory
tapeout流片把 GDSII 交给 foundry 做掩膜
BTO / MTOBefore / Mask Tape Out送厂前的数据整合检查；MTO 之后数据彻底锁死
run一次跑流把一串命令丢进 Queue 跑完的一轮，几个钟头到几天
Try试版本同一阶段试不同参数的多版（FLP1、FLP2），比哪个结果好

三、数据：别人交给你的文件

出处：数据准备、lib 与 rc tech

缩写全称 · 中文它在流程里是什么
netlist网表（.v / .v.gz）逻辑连接关系：谁连谁。PR 的第一份输入
GDSII / GDS版图数据PR 的最终输出，foundry 拿它做掩膜
DEFDesign Exchange Format物理信息交换格式：die 大小、单元坐标、port 位置都在这
LEFLibrary Exchange Format技术描述格式，分 tech lef 与 cell lef 两种
tech lef工艺 LEF有哪些金属层、线宽间距、via 规则，是 DRC 的源头
cell lef单元 LEF每个 cell 多大、pin 在哪、什么形状
libLiberty · 时序库cell 延迟表：给定输入转换与输出负载，查出延迟
rc techRC 工艺文件线的寄生参数模型，同一根线在不同 corner 下 R、C 不同
TLU+ / ITF两种 RC tech 格式TLU+ 是 Cadence 的叫法，ITF 是 Synopsys 的叫法，同一类东西
SDCSynopsys Design Constraints时序"要求"：周期多长、外部给多少延迟、哪些是假路径
MMMCMulti-Mode Multi-Corner多模式多端角配置，实际落在 viewDefinition.tcl 里
SPEFStandard Parasitic Exchange Format抽出来的真实寄生 RC，PT 用它算线延迟
PG netlist带电源地的网表电源网络也连好的网表，做 LVS 时用它
UPFUnified Power Format低功耗意图：哪块能关电、工作在什么电压

四、时序：这门课的心脏

出处：Setup 与 Hold、MMMC

缩写全称 · 中文它在流程里是什么
setup建立时间数据不能太晚：下一个时钟沿来之前必须稳定
hold保持时间数据不能太早：当前时钟沿采完之后才能变
slack余量到达时间与要求时间之差，必须大于等于 0
arrival / required到达时间 / 要求时间一个是你实际什么时候到，一个是规定最晚什么时候到
WNSWorst Negative Slack最差那条路径差多少；负数就是没过，日常就看这一个数
TNSTotal Negative Slack所有违例路径的 slack 累加，衡量"烂得多不多"
skew时钟偏斜同一个时钟到达两个触发器的时间差
insertion delay时钟插入延迟时钟从源头走到触发器花了多久
corner端角工艺/电压/温度/RC 的一组组合，代表"一种可能的芯片"
PVTProcess / Voltage / Temperature工艺、电压、温度，也就是 corner 的三要素
SS / FF / TTSlow-Slow / Fast-Fast / Typical管子和线都慢 / 都快 / 都典型
WCSWorst Case SlowSS + 低压 + 高温 + RCmax，查 setup 用它
BCFBest Case FastFF + 高压 + 低温 + RCmin，查 hold 用它
OCVOn-Chip Variation同一颗芯片内部也有快慢，统一加个百分比余量
POCVParametric OCV用统计分布代替固定百分比，更准也更省
derate降额系数OCV 的落地方式：晚路径乘 1.05、早路径乘 0.95
STAStatic Timing Analysis静态时序分析，不仿真、靠遍历路径算时序
PTPrimeTimeSynopsys 的 STA 签核工具，报告以它为准
RCmax / RCmin最坏 / 最好 RC线最慢与最快的两种假设，分别给 setup 与 hold

五、物理：绕不通的时候看这些

出处：PR 全流程九步、LEF 详解

缩写全称 · 中文它在流程里是什么
DRCDesign Rule Check设计规则检查：线太细、间距不够就报错，必须清零
LVSLayout vs Schematic版图与网表是否一致，多一根线少一个孔都算错
via通孔上下两层金属之间的连接柱
pitch节距相邻两根线的中心距，工艺定死，单元高度按它算
track布线轨道线只能走在固定网格上，轨道数决定能走多少线
M1~M9Metal 1~9第几层金属，下层细、上层粗，走线方向逐层交替
1P9M1 Poly + 9 Metal工艺层数的写法：1 层多晶硅 + 9 层金属
OBSObstruction单元内部不许走线的区域，摆单元时工具自动避开
antenna天线效应长金属在制造中积电荷打穿栅氧，靠跳层或二极管泄放
density密度单位面积里有多少图形，太低太高都影响良率
congestion拥塞走线资源不够，route 绕不出来；根因通常在 floorplan
utilization利用率单元面积占 core 面积的比例，定太高必然拥塞
halo保护区macro 周围不许摆单元的一圈缓冲，用来留走线通道
tap cell / endcap衬底接触 / 边界单元没有逻辑但必须铺的单元，保证衬底电位与边界完整
NDRNon-Default Rule非默认布线规则：给时钟等关键信号加宽、加倍间距
IR drop电压降电流流过电源网络导致电压下降，降太多单元会变慢甚至失效

出处：数字电路基础、Pin 与 Port

缩写全称 · 中文它在流程里是什么
stdcellStandard Cell · 标准单元库里的基本逻辑单元，高度统一，工具自动摆

CLK / CKClock触发器的时钟端

SYMMETRY对称性lef 里声明这个单元允许沿哪个轴翻转
MUXMultiplexer · 多路选择器多选一的组合逻辑单元
BUF / INVBuffer / Inverter缓冲器 / 反相器，用来驱动长线、重整 transition
ALUArithmetic Logic Unit算术逻辑单元，CPU 里做运算的那部分
